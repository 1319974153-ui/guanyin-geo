# 观引 0.48 简单模式交付约定
沿用本仓库与已有数据模型、权限、密钥和预算接口。默认三个入口：今天、待我确认、效果；专业工具仍可访问。豆包优先，其他平台可保存独立实测证据。
核心流程：网址或资料 → 核对业务卡 → 五个初始问题 → 一次授权排队写作和质检 → 集中审核 → 平台交付 → 网页检查和周期报告。付费工作需要自己的模型配置及确认；不自动公开发布。消费端原文需真实取得，未知条件不补猜。浏览器无人值守采集不是已验证能力。
每份安装保持独立数据、密钥和身份；版本 0.48.0，Mac arm64 与 Windows x64 分别打包验收。旧版保留用于回退。新用户不需理解版本、事实字段或模型参数；重试不得重复建档或排队。后台执行需要明确开启，电脑休眠关机期间不可执行。
