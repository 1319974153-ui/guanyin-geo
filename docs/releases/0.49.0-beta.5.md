# 观引 GEO 0.49.0-beta.5

## 个人公众号浏览器辅助发布（开发预览）

- 已审核稿件会自动生成公众号排版与摘要，并建立本机待发任务。
- 桌面版会在独立、持久的公众号官方窗口中等待账号登录，随后尝试打开图文编辑器、填写标题与正文，并按已选择的“发布”动作请求平台处理。
- 平台要求的扫码、短信、滑块、封面选择或二次确认始终保留给账号本人。观引不会读取或导出 Cookie、密码、短信验证码，也不会绕过验证。
- 取消了“手填公开链接／回执”表单。点击或页面提示不是发表成功；仍需以平台可见回执和公开页为准。

## 验收边界

本版本通过自动化单元与桌面构建验证；尚未在“温舒可可”个人号的真实公众号后台完成保存草稿或发表验收。公众号页面结构、账号权限和安全验证均可能令自动脚本暂停，届时任务会保留在本机窗口，不会重复点击发表。
