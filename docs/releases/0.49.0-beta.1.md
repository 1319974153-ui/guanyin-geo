# 观引 GEO 0.49.0-beta.1

日期：2026-10-20。预发布测试版，供开发验收；不是全平台自动发布正式版。

## 本版变化

- 简化建档、写作模型配置和首稿流程，统一写作、导入、预览、账号选择及逐目标结果。
- 包含观引自研发布连接器 0.2.3，不依赖 CSDN 付费同步会员。
- 发布平台目录包含 35 项接入目标；抖音长文/图文、小红书长文/图文分别列出。待开发渠道仍不可发送。
- 新增填稿核对记录：重新检查原编辑页的账号、标题和正文，保存经过平台归属校验的编辑页链接。回执丢失时只读取原页面，禁止重新填稿或发布；稿件变更时保留待核对状态。编辑页记录不代表平台已保存草稿或公开发布。
- 正常重启优先复用本实例端口，保留扩展配对；若端口被占用，使用新端口并提示重新配对，不关闭占用端口的其他程序。

## 使用与升级

1. 下载对应系统 ZIP，解压到独立新目录，双击“启动观引”。自带 Node 运行时，不需要 Codex 或预装 Node/npm。
2. 每个客户使用自己的安装、数据目录和 Chrome 资料。首次启动为空；共用一个本地实例会共享工作区。
3. 浏览器连接器位于 `browser-extension` 文件夹。由用户在 Chrome 扩展管理页加载，选择平台、授予对应域名权限并配对。旧扩展升级要重新加载并确认 0.2.3。
4. 平台登录状态由浏览器及平台保存；观引不读取或导出 Cookie。本机保存配对、核验与任务记录。登录过期或换号须重新核验。
5. 不覆盖旧程序目录。先在旧版导出业务备份并停止旧实例，再在新版恢复资料；模型密钥与发布连接需要重新核对。每个全新安装默认独立，不会自动搬走旧资料。
6. “停止观引”只停止自己的实例；“诊断观引”显示运行状态；“卸载说明”停止服务并说明数据保留位置。不会自动删除业务数据。

安装包不包含作者账号、配对令牌、数据库或测试稿。35 项完整计划见仓库 `docs/全平台发布接入计划.md`。本版不承诺全部社交网站可无人值守自动发布。
