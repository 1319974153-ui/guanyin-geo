# 观引 GEO 0.49.0-beta.2

2026-10-21。开发验收候选版，正式发行未更新。它不代表全部平台已支持自动公开发布。

## 日常操作

1. 首次仅填品牌名称和一句介绍，个人、产品和企业统一作为品牌；网站、资料导入、目标问题和关注平台可以展开补充。默认关注豆包、腾讯元宝、通义千问，可以调整。
2. 工作台按实际数据给出下一步：继续原任务、确认已有文章、选择账号发送。没有模型也能直接写作或粘贴文章，不必先手动记录 AI 回答。
3. 在编辑器勾选账号；选择后才出现该组账号支持的发送方式与确认。可保存本机草稿，也可按平台能力填稿或保存平台草稿；公开发送仅向已开放的账号提供。
4. 发布结果页显示原稿和逐平台回执。等待中的任务自动只读刷新；断网退避，切换品牌停止旧请求。结果未知时保留原任务，不自动重发。
5. 清空浏览器记录或使用另一个浏览器后，可从服务端恢复对应稿件版本的社交平台回执；改过正文、声明或图片的稿件不会套用旧版结果。

## 本版范围

- 观引自研连接器 0.2.8；保留头条当前编辑页的有效草稿编号，原稿链接不再丢失编号；不新增扩展权限，扩展重载后的整链路验收待完成。
- 历史真实验收包括 CSDN、头条、知乎账号与填稿，以及知乎平台草稿。公开自动提交仍默认关闭，未通过的目录平台不能因勾选而发送。
- 头条新建编辑页到唯一草稿编号恢复仍需开发与实机核对；抖音现有草稿保护、小红书暂停验收仍保留。
- 网页、草稿、提交成功、公开可访问、AI 引用分别记录，不互相替代。真实消费者回答仍需取得原文，不会以模型 API 生成结果冒充。
- 程序和账号配置由客户自己拥有。新解压实例为空，不包含作者账号、密钥、数据库或验收文章。

## 验收边界

代码测试、归档启动/API 流程验收和真实浏览器/Windows 桌面验收分别记录。已通过浏览器实际操作核对统一品牌建档、无模型首稿保存、刷新恢复、发布结果空状态和窄屏账号连接。模型配置改为可选展开；页脚版本由构建读取，避免显示旧版号。任何归档自动检查通过都不等于真实平台发送完成。

最新版源码见 PR #2；以归档内 manifest.json 的 source 和 dirty 字段对应具体构建，不用旧版 Windows 双击结果代替本版。
