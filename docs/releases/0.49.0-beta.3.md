# 观引 GEO 0.49.0-beta.3

2026-10-29，Mac Apple Silicon 开发预览。目标流程为填写品牌资料、连接自有模型生成并确认文章、登录账号、勾选可用渠道、查看逐平台结果。

## 本次更新

- 掘金纯文本草稿：自动识别当前账号、填写、保存编号草稿、重新打开核对完整正文，结果回到观引；真实账号非公开验收已完成。公开提交和图片稿未开放。
- 通用 MetaWeblog：连接自有 HTTPS 博客，先存私有草稿、核对原稿再发布，未知结果只读恢复、防止重复写入。凭据加密保存，品牌隔离。协议回执测试通过，真实站点仍待验收。
- 个人主体公众号：生成摘要和交付稿，供本人发布；不是已接通自动发表。
- 账号连接区布局、掘金连接按钮修正；安装包能力清单与真实开关保持一致。
- 正常更新保留原账号、稿件和回执；不复制其他浏览器登录，不增加开发者密钥或运行数据。

## 使用及限制

解压后打开“观引桌面预览.app”。已有版本先保存稿件再正常退出；新版使用原本机资料目录。模型由客户在产品内自行配置，未连接时明确提示，不会自动消费。

本版仍为未公证的预览版。各平台的可执行动作取决于实际账号与权限。平台目录有 36 个模式/入口，不代表全部已自动发布。头条权限、抖音登录限制、思否短信以及其他未接通平台仍需分别处理。小红书实机验收仍按用户要求暂停。微信公众号与百家号的既有后台访问限制不绕过。

1014 项自动测试通过；真实平台证据见《平台能力与验收状态》。最终压缩包的启动、保存、重启、签名、数据扫描和摘要记录随 GitHub 发行附带。未发布新的 Windows、Intel Mac 或 Linux 桌面包。
