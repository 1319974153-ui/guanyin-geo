# 观引 GEO 0.48.2

2026-10-13

## 更新内容

- 默认黑曜石深色，局部 Canvas 折射光与鼠标跟随高光；光效自动开启，无额外开关。保留浅色，系统减少动态效果偏好生效。
- 今天首页以一个明确的下一步为主；平台标签支持鼠标与方向键切换，详情和检测目标一致。
- 豆包、DeepSeek、Kimi、腾讯元宝、通义千问、文心、ChatGPT 分别保留真实回答证据；零样本显示尚未采样。
- 统一桌面、手机、表单、弹窗和空状态；不依赖在线字体或新的第三方 UI 包。

## 从 0.46 公开预览版升级

此次还公开之前开发分支的简单模式、业务资料确认、五个初始问题、草稿与质检排队、发布交付、证据周报、试用数据区分、模型费用预算和独立启动包。完整范围见 README 和随应用提供的功能文档。

模型连接属于使用者；消费者平台采集仍需复制问题、打开平台、粘贴真实回答。社交平台发布仍需相应平台操作，不保证 AI 收录或推荐。

## 验证与边界

- 界面已在 Mac 浏览器检查桌面、390px 手机视口、平台/方向键切换、对应检测弹窗、深浅色、主要路由；独立设计复核通过。
- 默认光效和无开关状态已重新构建并核对；全量自动测试 576/576 通过。
- 精确归档的校验和及安装包验收摘要随 GitHub Release 提供。
- Windows 0.48.0 曾通过真实设备启动、独立实例、中文路径与重启检查；**0.48.2 Windows 桌面双击验收等待用户补充**，不沿用旧版验收作为本版通过证明。
- 不包含完整屏幕阅读器认证或低性能设备专项性能结论。

## 安装与迁移

新用户解压后双击“启动观引”。程序内含 Node 运行时，无需 npm 或 Codex。

旧用户先在旧应用导出业务备份并停止旧实例，再解压新版、恢复备份并核对模型连接。每个新解压实例有独立数据目录；不要直接删除旧业务数据，也不要把自己的已运行目录重新打包发给其他人。

## 设计参考

参考 [Paper Shaders](https://github.com/paper-design/shaders) 的光材质与 [Motion Primitives](https://github.com/ibelick/motion-primitives) 的交互反馈。本版以原创原生 CSS、JavaScript 和 Canvas 实现，没有复制其源码或引入新 UI 依赖。
