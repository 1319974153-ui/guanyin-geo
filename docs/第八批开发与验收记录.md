# 第八批：配图复用、完整备份与单次定时发送

本批沿用用户已批准的五项重点。当前是 beta.5 开发预览，正式交付门槛仍未全部通过。

## 本批实现

- 稿件配图保存在本品牌素材库；保存、重开和正常重启保留原图与顺序。另一篇稿件可复用图片，对外使用确认按稿件分别保留。
- 文章、图片或使用确认发生变化后，旧审核与发送批准失效。缺图或目标平台不支持当前图文形式时明确阻止发送，不悄悄删图。
- 完整离线 ZIP 包含稿件图片原件；导入先保存恢复副本，不直接覆盖当前工作区。恢复时重新核对图片、清除旧审核与使用确认。
- 单次定时发送限于现有 WordPress、博客园、Typecho、MetaWeblog、个人官网和语雀 API 账号。冻结已审核稿件、账号、时间和额度，默认关闭。
- 正常重启保留未来计划；错过两分钟执行窗口不补发；取消停止后续账号，已经开始但结果未知的账号只核对原任务，不自动再发。
- 恢复备份或升级回滚暂停旧定时许可。页面关闭不等于取消，本机服务需运行。
- 备份入口和图片操作布局已简化，当前指南区分公开历史版本、本地预览与真实验收范围。

## 实际界面证据

在专用隔离品牌中，用真实文件选择器上传两张测试色块，调整顺序、保存、重开、重启本地服务、复用素材均通过。未使用客户图片、真实账号或模型密钥。

完整 ZIP 已在界面下载并重新导入，两张图片 SHA256 与原件相同；导入后当前修改稿件未被覆盖。第一次在侧边浏览器点击“恢复”后控制超时，没有出现恢复结果；用户随后取消确认框。解锁后改在最终 Mac ZIP 的隔离工作区完成原生恢复确认，恢复成功并自动生成恢复前保护备份。原稿与两张图片顺序恢复、原图 SHA256 一致，旧审核与使用确认清除。完整 ZIP 当前依赖同一工作区的签名密钥，不宣称任意新电脑跨工作区恢复。
