2026-10-23，Mac arm64 内部预览 r48。客户在观引中登录自己的账号后，从统一发布中心选择 51CTO，可保存草稿或提交审核，无需安装扩展或手动配对。

## 实现与证据

- 登录会话按连接隔离，重启保留。历史内部验收登录仅允许一次归属到一个连接；干净安装和其他连接不共享该登录。
- 只在空白编辑器填入审核稿；保存后从当前账号草稿箱找到唯一标题，重开并核对完整正文及 AI 声明，才记录草稿成功。
- 已保存稿件转公开时复用原编号，不重新创建。提交前再次核对账号与完整内容。
- 基础信息的“确认”只保存元数据；最终“发布文章”才是提交边界，需通过本机提交授权。
- 实机草稿 2103828 完成完整内容核对；同稿提交一次取得文章 15031390，官方成功页为“发布成功 - 待审核”。r48 重启后自动只读恢复原任务，观引显示“已提交，待确认”及原回执链接。
- 中间验收曾将元数据确认误判为提交。确认官方文章列表为空、原草稿仍存在后，仅修正隔离测试任务的尝试标记并留审计记录；因此本轮不宣称初版从新建到公开全程无中断通过。

## 能力边界

目前实测为无封面技术文章，正文按纯文本（含 Markdown 标记）写入。自动分类限软件研发相关稿件；未知分类、缺失标签、非原创或非公开设置会保留原稿并提示处理，不擅自改稿。富文本与图片文章尚未验收。

成功页是提交证据，不能证明审核通过或公开访问。本轮尚未实现 51CTO 匿名公开全文自动核验；不将审核中的文章显示为已发布。其他平台状态见《平台能力与验收状态》。

全量自动测试、真实平台验收、Mac 包启动与 Windows 验收分别记录；本轮无 Windows 验收，不上传正式发行包。客户模型仍可自行配置，本轮未连接或调用付费模型。
