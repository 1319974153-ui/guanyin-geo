# 一键社交发布接入设计

日期：2026-10-19。状态：本机连接、队列和 CSDN 适配实现中；已通过自动化测试，真实平台验收待完成。

## 2026-10-19 用户明确的自主实现边界

观引独立实现多平台发布。CSDN 仅作为交互参考和一个投稿目标，不使用 CSDN 的付费多平台同步服务、不要求购买其会员，也不把第三方同步产品包装成观引功能。参考公开操作流程，独立编写账号连接、平台适配、队列和回执代码；不复制第三方品牌、专有代码或付费权限。

最终普通用户界面固定为：写/粘贴/导入文章 → 勾选已登录的目标账号 → 选择「保存草稿」或「直接发布」→ 一键执行 → 查看逐平台结果。正文、封面、摘要默认沿用；必要的平台差异就地提示。首次连接仅需安装观引自己的连接器、授予所选平台权限并登录；日常隐藏配对、租约、哈希和队列配置。

- 保存草稿只有取得平台草稿回执才算成功；填入编辑器单列为准备完成。
- 直接发布只有通过该平台独立验收才开放，不因出现复选框就宣称支持。
- 某个平台需要验证/补材料，仅暂停该目标，其余已授权目标继续；结果未知禁止自动重发。
- 观引源码与发布连接器不依赖 CSDN 同步会员；平台自身的发文限额、账号权限仍遵守，外部模型等服务费用另计。

## 用户流程

用户首次建立品牌/个人 IP → 在 Chrome 登录所选平台 → 给观引扩展授予所选平台访问范围 → 核对真实账号 → 选择文章和目标账号 → 一键发布 → 逐平台查看实际结果。正常发布不依赖 Codex；登录过期、验证码和缺少必需材料时才进入待处理。

本轮先实现用户点击发起的发布。定时全自动属于后续授权调度阶段，不能因用户连接账号便自动发布所有草稿。

## 首批顺序

1. CSDN：标题、正文、必需标签、声明、提交及平台回执。先完成一个账号从登录到实际文章结果的完整验收。
2. 头条：复用队列和授权边界，增加正文/封面适配与审核状态识别。
3. 知乎：复用队列，增加专栏文章及实际文章编号/回执识别。
4. 小红书、抖音图文：作为独立图文能力处理，不能把长文接口当作图文投稿。

WordPress 已有适配器可以先验证统一队列。界面只显示通过验收的渠道为可执行；其余仍显示待接入。

## 工程拆分和验收

- B01 浏览器连接：扩展与本机实例一次配对；验证端口、来源、实例标识与会话；按平台申请最小主机权限，不默认请求所有网址。平台 Cookie 不回传服务端，不写入普通日志或安装包。退出与更换账号使旧授权失效。
- B02 账号识别：连接成功必须有真实平台账号 ID、显示名称与有效登录证据；页面打开、扫码完成或存在 Cookie 均不单独算成功。单浏览器资料目录里的同站账号切换必须明确呈现，执行前核对快照身份，不宣称天然多账号并发隔离。
- B03 授权与队列：服务端固定工作区、品牌、账号、文章/封面哈希、动作和授权期限。存储逐目标任务、发送前状态及去重键，双击/并发/重启不新增重复文章。
- B04 CSDN 适配：编辑器配置、明确的单次提交、账号一致性核对、等待本人验证、解析实际文章 ID。失败不能先点按钮再盲目调用备用接口；不删除用户稿件。
- B05 真实回执：草稿、提交成功、审核中、已公开、被拒绝、结果未知分别记录。文章 URL 必须来自回执/公开页面，不能只拼接预计 URL。结果未知先核对，不自动重发。
- B06 头条和知乎：复用 B01—B05，每个平台独立真实验收。
- B07 本机生命周期：扩展休眠、浏览器退出、电脑休眠后恢复任务状态；本机程序或浏览器不运行时明确暂停，不承诺继续。定时策略另行配置时区、失效时间和每日额度。
- B08 干净交付：独立安装包与扩展包、许可、源码版本、无用户凭据、Mac/Windows 安装与重启验收；保留错误诊断及连接撤销入口。

## 2026-10-19：统一写作与分发界面

已将「写文章」和「选择发布账号」接入同一个编辑抽屉：粘贴或导入 Markdown/纯文本、排版预览、勾选真实账号、明确选择保存平台草稿/公开发布/仅填编辑器、逐账号查看结果。本机保存与平台草稿分开显示。改稿（包括排版按钮和导入）清除确认与旧版结果；管理员确认当前版本后可发送，普通编辑仍需审核。

当前能力按适配器开放：WordPress 接入现有草稿与发布接口；CSDN 仅填入编辑器。混选不兼容能力的账号会提示分组发送；头条、知乎、抖音、小红书不会冒充可自动发布。界面不调用 CSDN 付费同步服务。

执行前保存版本与账号对应的记录；WordPress 使用稳定请求编号，存草稿后发布复用同一远端记录。一个账号失败不覆盖其余结果，结果未知不会自动重发。核对按钮只查询现有回执。CSDN 标签现已保存到任务记录，但实际标签控件与 AI 声明仍需后续真实平台验收。

验证：651 项自动测试通过；隔离环境中经浏览器实际操作验证本机保存、真实账号显示、能力禁用、改稿清除确认、桌面与手机布局、键盘到达填稿按钮。WordPress 未使用真实账号公开发文；CSDN 本轮没有新增外部提交。此批仅为 PR #2 开发交付，未合并或发布正式安装包。
