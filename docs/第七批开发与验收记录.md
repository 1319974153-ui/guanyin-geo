# 第七批开发与验收记录

本批继续围绕文章质量、一键发布、GEO 诊断与简单操作推进。记录的是已完成代码及隔离验收，不表示正式客户验收或全平台可发布。

## 已实现

- 整篇写作采用一次有限额度确认，覆盖选题、首稿、五项质检、按建议改稿各一次；后续阶段由客户点击执行，第二轮质检重新确认。模型、资料、问题与权限变化使旧额度失效，不后台无限重试。
- 账号或网络问题只阻断对应发布目标；已提交及结果不明的原任务继续核对，不重复提交。
- 回答采集可导入本地原文，复用原采样条件；时间需确认，候选链接需选定，演练不计入正式诊断。
- 排名依据需要具体来源、范围、时间、方法和结论核对；投稿申报任务明确为准备材料，不把材料完成当成刊登或获奖。
- 服务器返回状态后保留简化的三个主入口，已有明确选择的完整模式仍保留。
- Mac 桌面升级先保存并核对业务数据备份，完成升级前禁止业务写入与后台执行；启动失败可以安排下次启动恢复，保留失败现场。

## 实际验收

- 真实浏览器界面使用明确标记的本地模拟服务走通选方向、生成草稿、质检、改稿；四次模拟请求，真实模型调用零次。原文版本保留，旧质检失效，下一轮质检需要新确认。
- 浏览器导入一条演练回答，原文与选定链接保存，未计入正式效果。
- Mac 隔离旧数据升级，品牌和五个问题保留；四个备份文件核对通过，应用退出后端口关闭。这是构建目录启动检查，非最终归档安装包验收。
- 中间完整回归 1619/1619 通过；此后权限竞态、模式迁移和排名依据合同分别补充专项回归，下一批结束后再执行最终完整回归。
