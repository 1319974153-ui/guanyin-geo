# 第五批开发与验收记录

日期：2026-11-12。目标：开发助手负责方案、实现与交付，用户不承担技术拆解和测试工作。本文记录实际实现，不代表全量平台或正式安装包已完成。

## 本批交付

### 品牌资料集中核对（Q08）

在品牌知识库增加“集中核对资料”。展示已有候选资料、完整内容、出处、版本与产品范围；默认不选中。用户选择可公开用于稿件的资料后一次确认，后续选题、写稿和改稿继续复用。缺内容/出处、未生效/过期、归档产品或原件已有新版会阻止确认。

每页 50 条并可翻页，前页全不合格也不阻塞后续资料。服务端校验选择与预览一致，保存全部成功才更新；连接中断重试复用原批次。原文、旧版本与确认记录保留，修改资料会清除旧确认批次。辅助按钮不会误触发表单提交，等待期间切换工作区不会误保存，晚到的响应不会覆盖新修改。

### 模型设置简化（Q09）

合并为一个服务商选择入口，常用模型预填，连接信息默认折叠；既有连接可沿用密钥和模型，不必反复输入。不改变配置时跳过重复保存和核验。“免费检查填写”只检查本地格式，保存配置也不调用模型；真实测试单独说明可能计费。失败保留输入，并按认证、模型、配额和超时显示对应下一步。当前只支持已有四个服务商网关，自定义地址后端和整次写作预算仍在后续范围。

### 诊断标签修改历史（D07）

推荐与引用核对仍是两个选择项，历史默认折叠。每次保存同时记录旧值、新值、操作者、时间、原回答摘要与采样条件；不改变原文、采样日期或已归档报告。重复请求不增加记录。原回答或采样条件改变时旧标签失效回到待核对。备份恢复保留仍存在回答的较新审计；移除范围的历史留在恢复前保护备份。与诊断修复待办的完整关联仍待继续开发。

### 当前账号与历史能力分开（P01）

发布页首先显示当前账号能否使用；历史验收放入折叠说明，注明日期、版本与范围，缺记录的字段明确显示未记录。历史通过不会解除当前发布限制，也不代替本次账号和稿件准备检查。本批没有新增真实平台发布。

### Windows 免插件打包器（I06）

增加独立 Windows x64 桌面打包工具，接受已准备的 Electron 运行时，检查 PE 架构、版本、必要资源和文件白名单。干净构建不带用户数据和密钥，生成中文启动/卸载说明、文件哈希、ZIP 校验和；重新打开 ZIP 核对内容，不覆盖旧包。

7 项打包测试使用合成运行时，只证明构建逻辑。当前尚未生成可交付的真实 Windows 产品包，未做 Windows 真机启动或发布验收。
