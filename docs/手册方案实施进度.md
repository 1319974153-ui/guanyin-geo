# 手册方案实施进度

更新：2026-10-21。采用手册的业务流程，结合观引自己的数据、连接器和账号能力实现。参考资料：[AIDSO 手册](https://s12is4u3s19.feishu.cn/wiki/U9f5wCMKziO4gdkoOTLcD4Xkn1c)。手册媒体投放涉及积分和媒体费用，此轮未接入收费投放或购买服务。

## 目标流程

品牌（包括个人、产品和企业） → 确认业务资料 → 目标问题 → 真实 AI 回答与信源 → 内容缺口 → 写稿 → 选择授权账号 → 平台执行与回执 → 同条件复测。

日常入口继续使用“今天、需要我处理、效果”。只在缺资料、本人验证、预算或事实变化时让用户处理；消费者答案和模型 API 输出分开，不把发布量当成被 AI 推荐。

### 2026-10-21 操作简化增量

- 品牌统一：移除品牌/产品/个人选择，个人姓名和产品名都作为品牌；历史类型元数据不改写。两项建档；手工 AI 采样不再阻挡写稿；目标和高级配置渐进展开。
- 下一步由已有任务、稿件和当前版本回执决定，避免再次创建同一批内容；工作台保留写新文章入口。
- 发布结果页接入浏览器任务，支持只读自动刷新，区分平台草稿、已填稿、已提交和未知；不再需要去账号设置找发送结果。
- 新浏览器从服务端恢复相同稿件版本的回执，图片稿另核对媒体指纹；切换品牌丢弃迟到结果并自动读取新品牌。
- 浏览器已恢复：本轮实际完成统一品牌建档、资料编辑、无模型首稿保存、刷新恢复、发布结果空状态与未选账号时的操作门槛检查；窄屏发布账号下拉框挤压已修复。平台模拟回执不能视作真实投稿。
- 安装器候选版本升为 0.49.0-beta.2，以本版归档及清洁安装记录验收；未替换正式发行。

自动回执只显示连接器或网站 API 已返回的事实，不自动生成新的平台回执。它不增加新的平台适配能力。
