# 观引全平台发布接入计划

更新：2026-10-20。实施分支：`codex/simplify-first-business-flow`，PR #2。

## 产品目标与核对范围

观引自行实现「写作/导入 → 勾选账号 → 保存平台草稿或直接发布 → 逐平台回执」。用户登录自己的账号；使用观引自己的连接器，不依赖 CSDN 付费同步服务。默认沿用标题、正文、封面及摘要，仅在平台必填项缺失时提示。

2026-10-19 在用户已安装的 CSDN 同步助手“平台管理”界面只读核对到 18 个入口：微信公众号、微博、知乎、掘金、百家号、博客园、抖音长文、抖音图文、小红书长文笔记、小红书图文笔记、头条、51CTO、简书、思否、开源中国、哔哩哔哩、腾讯云开发者社区、阿里云开发者社区。该目录只能证明存在入口，不能证明它们全部支持直接公开发布。

官方说明入口：https://sync.csdn.net/ 。官方页面介绍了多平台同步与草稿能力；具体动作以各平台实测为准。此次未使用其收费同步功能、读取其凭据或复制专有实现。

在这 18 个入口之外，保留此前用户截图要求的渠道，以及 CSDN 自身，共计 **35 项接入目标**。Markdown/PDF 属于本地导出，不计入平台数量。抖音长文与图文、小红书长文与图文分别验收，B 站文章与视频也不能互相冒充。

## 已有能力与本轮交付

- WordPress 已实现账号、应用密码、草稿与发布适配；仍需使用者验证自己的身份及权限。
- CSDN、头条、知乎：真实账号与标题/正文填入已验收。头条显示草稿已保存，知乎显示自动保存，但连接器统一回执仍为「已填入 · 未提交」；平台元数据、平台 AI 声明、主动保存草稿与最终发布尚未完整验收。
- 抖音图文、小红书图文：已有适配代码，尚未通过完整实机验收。抖音现有未发布稿受保护；小红书按用户要求暂停验收。
- 其余 29 项：尚未实现可执行适配，不申请账号权限，不显示可发送。
- 本轮补齐腾讯云、阿里云、抖音长文、小红书长文四项，并将完整目录接到发布中心。清单与账号能力分开，目录不能授予发布能力。

## 每个平台共用的完成条件

每个平台必须独立完成以下检查，不能因共享同一域名而沿用另一个模式的验收：

1. **身份**：从用户可见的账号界面取得唯一账号 ID，执行前重核对；登录过期与换号停止该目标。不导出 Cookie，不将身份信息写入安装包。
2. **填稿**：验证空白编辑器，既有标题、正文、媒体或未发布提示均受保护。标题、段落、列表、图片、摘要、分类、标签和平台声明按实际要求适配。平台强制封面时不能把任务标为完成。
3. **草稿**：取得草稿编号、实际回执地址或明确保存证据；自动保存、仅填入、保存成功分别记录。不能把本地保存叫作平台草稿。
4. **发布**：只对用户确认版本执行一次最终提交；独家首发/付费勾选不会自动开启。验证码交给本人；提交结果未知先核对原任务，禁止重新发一篇。
5. **回执**：区分提交、审核中、拒绝、公开和结果未知。公开 URL 来自平台实际回执或页面；不拼接猜测链接当成功。
6. **恢复和隔离**：同稿同账号重复点击、断网、扩展休眠、应用重启、账号切换、品牌切换各有测试；单目标失败不覆盖其余结果。
7. **交付**：先自动测试，再真实账号验收；报告精确到版本、动作、账号及结果。公开发布需专项授权，当前验收授权仍只含账号与填稿。未经实测的动作保持禁用。

## 简化用户操作

- 主流程只保留写文章、选账号、选择保存草稿/直接发布、查看结果。
- 账号列表只显示使用者自己连接的账号；全部平台目录默认折叠。
- 首次使用平台时才申请该平台权限；不会一次索取全部网站访问权。
- 自动沿用稿件素材并给出平台适配预览；需要用户处理的只有登录验证、确实缺失的必填素材和异常。
- 一个按钮建立逐平台任务；保存草稿或公开发布按每个账号的已验收能力开放，失败目标可单独处理。
- 仅靠品牌/个人 IP 名称无法确定真实事实、素材权利和费用预算。首次建档保留一次简短确认；后续在用户授权范围内复用，避免反复填表。
