# 公众号稿件与接口接入

2026-10-28。用户确认“温舒可可”为个人主体；本轮用户已手动发表订单案例，不重复提交。

## 当前可用流程

多平台发布列表 → 准备公众号稿件（自动带入当前已审核文章）→ 复制排版正文或下载 HTML/TXT → 由本人在公众号发表。

入口复用现有品牌、AI 写稿和审核流程。生成文章仍需用户配置文本模型并确认费用；本轮没有调用付费模型。默认从正文提取最多 120 字摘要，不调用模型、不额外收费；署名、摘要修改、阅读原文放入可选设置。支持分别复制标题、摘要和排版正文。禁止把演练稿、未审核稿或事实已变化的稿件导出为已审核材料。当前文字正文不接受图片，避免未经微信素材上传后静默丢图；封面由本人在后台选择。

准备、复制、下载不会创建平台草稿、发表文章或发出群发，也不会自动生成成功回执。

## 官方权限边界

微信自 2025 年 7 月起收回个人主体、未认证企业等账号的发表接口权限。个人主体不可通过登录自动获得发表权限。草稿权限须单独核对，不能从账号类型推定。

- [发表能力说明](https://developers.weixin.qq.com/doc/subscription/guide/product/publish.html)
- [创建草稿](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_add.html)
- [发表提交](https://developers.weixin.qq.com/doc/subscription/api/public/api_freepublish_submit.html)
- [发表状态](https://developers.weixin.qq.com/doc/subscription/api/public/api_freepublish_get)
- [稳定访问凭据](https://developers.weixin.qq.com/doc/subscription/api/base/api_getstableaccesstoken.html)

## 代码与测试边界

`wechat-core.js`：排版、安全限制、权限说明和回执解析。
`wechat.js`：已登录工作区的只读排版接口；校验品牌和事实快照，不访问外部服务。
`wechat-client.js`：服务端官方接口协议，默认禁止网络操作；固定官方域名、禁止跟随跳转、不重试写请求，不暴露凭据或远端错误原文。
`wechat-workflow.js`：依赖注入的流程原型；并发抢占、防重复、原稿读回、异步状态检查。发表结果未知不再次提交，轮询不会变成写操作。

后两个模块尚未接入产品在线分发。测试使用内存存储和模拟微信响应，未声称完成真实授权或平台验收。生产接入仍需要加密凭据/令牌生命周期、将持久任务仓库绑定到产品调度、实际账号权限及内容回读验证；不得直接把内存测试存储用于客户环境。

官方发表状态成功只标记 `platform_published`；公开正文尚未核验，群发也未执行。没有 `publish_id` 的未知结果需人工查原任务，不能重新提交碰运气。

## 本轮限制与下一步

此前公众号后台访问被自动审批拒绝，本轮不通过浏览器、观引、CLI 或 API 绕过。本轮只做本地开发和模拟接口测试。个人号先使用可用的稿件交付流程；有权限的企业账号后续另行完成合规授权与真实验收。

原产品目录由另一任务使用，本改动隔离在 `codex/wechat-official-publishing` 分支，避免重启用户桌面版或覆盖并行修改。未更新正式安装包，未宣称全平台自动发表。

2026-10-29 更新：移除发布中心单独的“公众号稿件”快捷入口，统一从当前文章的平台列表进入。桌面实机已验证直接带入已审核文章、生成排版并复制正文，显示“已复制；尚未发表”。未访问公众号后台，自动平台草稿和发表仍未接通。详见《抖音与公众号验收-2026-10-29》。


## 2026-10-29 任务持久化补充

`local/wechat-task-store.mjs` 已实现本地 SQLite 任务仓库：工作区/品牌/公众号范围隔离、相同内容唯一任务、原子状态抢占、版本比较保存。数据库文件权限为 0600，不保存登录凭据。

`wechat-workflow.js` 对接可持久化仓库：租期未到不抢占运行中的任务；租期过后将中断任务变为结果待核对，凭已有草稿/发表编号只读恢复。缺少远端编号时不重新创建或发表。过期执行者的迟到结果不能覆盖新状态。扫码等待与真实授权回调尚未实现，本轮没有访问公众号后台。

相关测试 24 项通过，包括关闭并重新打开数据库、两个连接同时处理、跨工作区拒绝、旧结果覆盖拒绝、创建或发表中断后不重发。平台客户端由测试替身提供，这不是微信真实账号验收。

本仓库尚未挂到产品真实分发或桌面登录流程；线上能力标记保持不变。下一步仍是获准的真实会话适配、验证等待/恢复以及原稿回执验收。没有新建安装包，也不需要用户重启或重新登录。
