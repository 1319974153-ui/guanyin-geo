# 观引桌面预览使用说明

观引帮助你整理品牌资料、用自己的AI模型生成文章、向已连接的平台发送，并查看AI回答中的提及与引用。

当前是开发预览，平台能力以文章中每个账号旁的状态为准。Mac Apple Silicon与Windows x64均有预览包；Windows包尚待本轮真机验收。平台目录中的36项不代表都已支持自动发布。

## 开始使用

1. **打开观引。** Mac解压后打开“观引桌面预览.app”；Windows解压后打开包内启动入口。不需要安装Node或浏览器插件。
2. **填写品牌。** 个人、产品和企业都使用品牌名称与一句介绍。补入真实项目、优势与来源，确认允许公开的资料。
3. **连接自己的模型。** 在“文章与发布 → 账号与写作模型”中设置一次服务商与密钥。免费查看计划后，确认本次调用范围和费用再生成。
4. **让AI写文章。** 点击“AI自动写文章”，选通用目标或说出要求，再选择方向生成待审核稿。检查建议和平台适配都在同一篇文章中完成。
5. **勾选账号发送。** 第一次在观引内登录各平台；之后复用本机登录状态。确认内容后勾选符合当前操作的平台，点击发送，逐个平台查看结果。

界面主要有三个入口：**工作台、文章与发布、GEO诊断**。资料与详细设置放在次级入口，日常不必反复配置。

写作时可以一次确认整篇文章的有限调用额度，覆盖选方向、首稿、质检和改稿各一次；每一步仍由你点击执行，不会每天自行调用。超出本次范围或更换模型、资料后，会重新展示调用计划。费用估算与实际账单以模型服务商为准。

需要配图时，展开文章中的“配图”，从电脑添加或复用本品牌图片；顺序和使用确认随稿件保存，重新打开无需再选。最多9张，单张2 MB、合计8 MB。图片用于不同稿件时需确认该稿的使用权。不支持当前图片稿的渠道会说明原因，不会悄悄丢掉图片后发纯文字。

## 发布结果怎么看

| 显示状态 | 含义 |
| --- | --- |
| 需要登录 | 打开该平台窗口完成登录，观引自动识别；不用手工配对或核验 |
| 可填入编辑器 | 可以准备稿件，尚不能据此认为已保存或发布 |
| 草稿已保存 | 平台已有对应草稿，尚未公开 |
| 已提交／审核中 | 平台已接收，等待审核或公开核验 |
| 发布成功 | 已取得该渠道要求的发布回执与公开证据 |
| 需要处理／结果待确认 | 保留原稿与原任务，先打开查看或核对，不要反复新建发送 |

扫码、短信、滑块等本人验证在平台自己的窗口完成。遇到平台访问频繁或账号限制，观引暂停该账号，不反复触发验证码。自动提交未完成验收的平台不会被显示成已可直接发布。

## 资料与费用

- 只把已确认且允许公开的资料交给写稿流程。仅内部参考的资料仍保存在本机，不作为公开文章依据。
- 从内部改为公开需要再次确认，避免误公开。明确关联与原句核对不能代替人工识别所有敏感表达。
- 模型服务使用客户自己的配置。查看免费计划不会调用模型；实际生成、质检或改稿按界面确认执行。平台发布成功也不等于一定被AI引用。
- 未获得真实回答时，诊断会显示样本不足。手工消费端记录、模型API结果与演练分开保存和统计。

## 保存、升级和退出

日常双击打开即可。Mac数据位于 `~/Library/Application Support/GuanyinGEO-Desktop-Preview`；Windows位于 `%APPDATA%\GuanyinGEO-Desktop-Preview`。同一系统用户的应用更新继续使用原资料；平台会话保存在观引自己的隔离窗口，不复制Chrome登录状态。

新版首次使用已有资料时，会在启动自动任务前保存一份本机业务备份。升级前备份包括品牌、稿件、附件、任务、报告和解密所需的本机文件；不上传到网络，不代替另存到安全位置的完整离线备份。单次自动备份上限2 GiB、50000文件，空间不足或校验失败会停止升级并保留原资料。

如果新版未完成启动，可以在错误窗口选择“安排恢复升级前资料”，退出后再次打开完成恢复。本次失败的数据另存保留，不会删除。已经正常启用并产生新操作的版本不能使用这个启动恢复入口回退，以免丢失新回执或调用记录。升级备份不迁移或清除平台浏览会话；必要时平台仍会要求重新登录。

另存业务资料可进入“设置与完整功能 → 备份与恢复”，创建副本后下载“完整 ZIP”，其中包含稿件配图和附件原件。“导出资料 JSON”只包含资料与图片引用，不是完整附件备份。完整ZIP使用原工作区的验证信息恢复，不能仅凭ZIP在全新电脑导入；它也不包含模型密钥或平台登录会话。恢复后的图片稿需重新审核和确认使用权，旧的发送许可不会自动恢复。

正常退出会停止本机服务。中断后不明的发布结果先核对原稿，不自动重复发一篇。卸载时只移除程序可保留资料；观引不会自动删除用户数据。

## 当前预览边界

本预览没有通过所有平台的完整真实验收，也不承诺品牌被首位推荐。Windows真机、真实模型质量评测及最终正式发行仍按交付记录逐项验收。Mac包目前为本地临时签名，尚未Apple公证；若系统拦截，请保留提示交给开发方处理，不关闭系统安全保护。

历史逐平台验收过程另见“桌面版历史验收记录-截至20261028.md”；最新能力以应用构建清单、平台状态和最新交付回执为准。
