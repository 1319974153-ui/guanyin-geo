# 观引免插件桌面预览

这是 Mac Apple Silicon 的开发预览，尚不是全平台自动发布正式发行版。它自带运行环境，不依赖 Node、Chrome 扩展或 CSDN 付费同步产品。Windows 桌面包尚未构建验收。

## 使用

1. 解压，打开“观引桌面预览.app”。首次填写品牌名称和一句介绍。
2. 在发布中心添加头条、知乎、CSDN、抖音图文或小红书账号，在平台自己的登录窗口登录。观引自动识别账号；验证码由本人完成，不需要手动配对或核验。
3. 打开稿件，勾选已连接平台，选择“保存平台草稿”或当前开放的操作。结果自动刷新。保存草稿不等于公开发布，只有取得相应回执才显示成功。

开发预览提供博客园、WordPress、CSDN、知乎和 Typecho 的公开提交入口。2026-10-22 已核对博客园一次真实公开发布及自动全文回执；知乎公开正文已人工核验，产品仍保留“已提交”状态；CSDN 原稿遇到当日额度限制而未公开。WordPress、Typecho 的真实公开验收尚未完成。知乎已在新桌面环境完成首次登录、自动账号识别、非公开草稿保存、自动回执与重复操作去重。CSDN 已完成真实登录、自动填稿与平台草稿保存、自动回执、重启保留与重复点击防重验收；头条仍待取得可靠的保存结果。平台目录中的其他渠道不代表已经接通。第三方 QQ/微信授权跳转不在首轮支持范围，请使用平台内手机/扫码登录。

## 数据和退出

登录会话、品牌资料和任务保存在当前系统用户的 `~/Library/Application Support/GuanyinGEO-Desktop-Preview`。不同账号连接使用隔离浏览会话。不会读取或复制已有 Chrome 的登录状态，因此首次需要在观引内登录一次。

同一系统用户的多个预览副本有意共用此目录并只启动一个实例，升级不会丢失资料；不同系统用户的数据独立。预览数据与旧网页运行版分离。应用关闭时停止本机服务；中断且结果不明的任务不会自动再发一遍。

退出后可把 `.app` 移到废纸篓卸载程序，保留资料方便恢复。彻底清除资料需要用户另行手动删除上述目录；程序不会自动删除用户数据。

当前仅本地临时签名，未通过 Apple 公证。若 macOS 拦截打开，不要关闭系统安全保护；保留提示交给开发方处理。此包不作为正式公开发行包。

## 源码运行

Node 24 或更新版本，执行 `npm ci` 后执行 `node node_modules/electron/install.js` 下载官方 Electron 运行环境，再执行 `npm run desktop`。下载失败不会关闭证书校验。

构建：`node tools/package-desktop-mac.mjs <全新的输出目录>`。只复制运行时与允许的构建文件，不打包用户数据。

## r8 回执恢复补充

头条回执恢复同时支持草稿在当前窗口打开和新窗口打开；原编辑页因重启变空时，仍可只读核对草稿箱。只有账号一致、标题唯一、完整正文相同且具有稳定草稿编号和已保存状态才登记草稿成功。恢复不会重新填稿或提交。

### 登录受限与原稿处理（r9）

登录页明确提示“访问/操作/登录过于频繁”时，桌面版会停止该账号的自动检查，并在本机保留暂停状态。重新启动不会自动重试；等待平台恢复后，由用户点击“去登录”再尝试。程序不会猜测解除时间，也不会自动刷新二维码、触发短信或绕过验证。平台只在手机上显示的限制无法由电脑页面识别，应停止登录操作。

发布结果中的“需要处理/结果待确认”现在可以直接点击“打开平台处理”。只有仍匹配原账号的桌面连接才显示此按钮；它打开原任务窗口，不创建新任务、不重新填稿、不公开发布。

当前抖音仍为首次登录受限、未通过真实填稿验收；头条仍未取得有效保存回执。上述改动不能当作两个平台的发布能力验收通过。


## 博客园官方接口草稿接入（r11）

在文章的全部平台中点击博客园旁的“连接”，填写博客地址名称、用户名和平台 MetaWeblog 访问令牌。连接时自动核对博客归属，不需要插件或反复手动核验。令牌加密保存，修改身份时需要对应令牌；不要使用登录密码。

连接成功后，选择“保存平台草稿”，勾选博客园并保存。程序调用官方 `metaWeblog.newPost`，`publish=false`，再通过 `getPost` 比对编号、完整标题及正文。AI 辅助声明随稿保留。r11 已完成真实账号连接、草稿 23401085 保存、去重与重启回读。r12 增加同一原稿公开提交，真实公开验收另行记录。

请求中断保留同一个任务和已取得的文章编号；不会自动重发。账号页的“稿件与回执”可只读核对原稿。尚未拿到编号时，只查近期 50 条中唯一完整匹配的原稿；没有匹配就保留待处理，不按标题猜测、不重新创建。恢复备份会暂停连接。

官方接口文档：https://rpc.cnblogs.com/metaweblog/example

## r12 公开提交与新增渠道

选择文章 → 勾选已连接账号 → 保存草稿或公开发布 → 查看每个平台结果。CSDN、知乎和博客园从已保存草稿发布时继续使用原编号；不会重新建稿或覆盖平台中修改过的正文。重复点击或中断后保留原任务。

博客园接口接受提交后先显示“已提交”，匿名公开页完整正文核对后才显示“已发布”。CSDN、知乎以平台提交回执显示“已提交”，不能据此宣称审核通过。各平台验收结论不同，详见开头的当前状态；本包仍是开发预览，不作为正式发行包。

小红书已加入免插件登录及现有图文填入流程，真实账号验收仍暂停，未开放自动草稿与公开提交。头条保存失败、抖音登录受限仍未解决，保持原任务。35 个平台是接入目录，不代表全部可自动发布。

博客园回执现在与浏览器渠道一起显示在首页，重新打开文章也能从服务器找回原记录。

## Typecho 自建站（r22）

在发布账号或文章的平台选择区点击“连接 Typecho”，填写自己的网站 HTTPS 地址、用户名和接口访问密码。标准安装自动采用网站目录下的 `index.php/action/xmlrpc`；不同安装入口可在高级设置填写同源 XML-RPC 地址。网站必须启用 XML-RPC，并允许此作者账号写稿。连接仅读取账号身份，密码加密保存；不同品牌和账号分开保存。

连接后，在同一文章中勾选 Typecho，选择“保存平台草稿”或“公开发布”。程序先保存非公开原稿并核对完整内容，公开操作继续发布同一个编号。返回错误或断网时保留原任务，核对回执不会新建文章。平台接受提交后显示“已提交”；只有匿名页面的标题、完整正文和平台发布状态一致才显示“已发布”。默认主题及使用 `post-content` / `entry-content` 的主题可参与全文核验；不兼容的主题保留待确认，不冒充成功。

已完成隔离自动测试；尚未在用户网站真实验收。当前 Typecho 接入处理文字文章，不自动上传封面/图片，也不创建新分类。

## AI 写作入口

保存自己的模型连接后，可直接选择“准备 AI 写稿计划”。此步骤只整理品牌事实、问题和计划，不调用模型。确认调用与费用后才生成正文；真实产品使用用户配置的模型，不依赖 Codex。未配置模型、事实不足或额度不足时显示具体提示。


## 51CTO 图片文章和审核状态

登录自己的 51CTO 账号后，在文章发布区域勾选账号，选择“保存平台草稿”或“公开发布”。可选 0–9 张文末配图（单张最多 2 MB、总计最多 8 MB）；重开原稿会恢复已选择图片，不必重新选。图片或正文与原稿不一致时会停下说明原因。

平台成功接收但仍需审核时显示“已提交”，观引开启期间自动检查原文章。只有匿名完整正文和图片核对一致才显示“发布成功”；关闭应用时暂停，重开后继续。检查不调用 AI 模型，不会重发文章。当前 Mac 实测通过两图草稿保存和回读，纯文本稿审核通过后已自动核对并显示发布成功；图片公开提交仍待实测。此包为内部预览，Windows 尚未完成本轮验收。
