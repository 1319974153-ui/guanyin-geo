# 免插件桌面版交付约定

2026-10-22。目标：客户在观引内登录自己的账号，勾选平台后保存草稿或发布；账号校验、执行和回执回收由应用完成。

- 一个桌面入口。品牌、稿件、分发页继续使用现有业务代码，不增加另一套内容库。
- 先支持现有 CSDN、知乎、头条适配器；每种动作分别验收，未通过公开提交验收的渠道不伪装为可发布。其余平台保留真实接入状态。
- 应用内打开各平台自己的登录页，程序自动识别登录结果。平台验证码由本人完成。按工作区、连接分别隔离浏览会话，重启保留；不读取既有 Chrome 配置，不导入用户 Cookie，不上传凭据。
- 本机专属数据目录、独立测试端口和桌面输出目录，不修改旧验收实例。安装包不含开发者账号、测试稿、密钥或绝对开发路径。
- 本机服务与桌面主进程通过私有进程通信连接；第三方网页没有业务 IPC 权限，渲染层不能提交任意脚本、任意 URL 或文件系统路径。
- 复用既有冻结稿件、身份绑定、权限判断、防重复与结果未知保护。每次发送自动复查身份，换号必须暂停；不靠取消身份检查来减少点击。
- 更新后不要求加载、重载、配对 Chrome 扩展。旧扩展仅保留兼容路径，与桌面连接分开标记。
- 模型仍使用客户自有配置；本轮不调用付费模型，不参与第三方收费分发。

验收：隔离新用户启动 → 建档 → 应用内登录 → 自动显示账号 → 选择稿件/平台 → 草稿完整保存及真实回执 → 重启保留会话 → 重复操作不重发 → 断线/换号/关闭恢复 → 干净打包与退出。真实公开发文另以批准稿件测试，不以自动测试代替。

交付目标为 Mac 桌面预览与可复现源码；Windows 包必须单独构建并真机验收。未完成的登录/发布或平台兼容步骤须明确记录，不能标成已验收正式包。
