# 下载与使用

更新：2026-11-13。**当前公开可下载的是 0.49.0-beta.3 Mac 桌面开发预览；没有稳定版。** 本地源码版本为 0.49.0-beta.5，新增功能正在完成本批验收，尚未公开发行。

## 公开下载

打开 [GitHub beta.3 发行页](https://github.com/1319974153-ui/guanyin-geo/releases/tag/v0.49.0-beta.3)，下载 Mac Apple Silicon 的 ZIP、对应 SHA-256 文件，并查看随包验证记录。beta.2 是更早的历史版本；此前文档中的 beta.4 下载地址无对应公开发行，已移除。

完整解压后打开“观引桌面预览.app”。包内含运行时，不需要 Node、npm、Codex 或浏览器插件。该版本未做 Apple 公证；系统阻止运行时请保留提示反馈，不关闭系统安全保护。

**本轮 beta.5 的 Mac 与 Windows x64 包等待最终构建和各自验收回执。** 不提供尚未发布的下载链接；本地预览包、源码版本与 GitHub 公开发行分别记录。Windows 真机验收尚未完成；Intel Mac、Linux 也不能按 Mac Apple Silicon 结果视为已验收。

## 开始使用

1. 填品牌名称与介绍，补充允许公开的真实资料。
2. 在产品内配置自己的文本模型，查看并确认调用费用后生成文章。
3. 审核内容，在观引内登录已支持的平台，勾选可执行的账号发送。
4. 查看每个平台的原稿与结果；草稿、提交、审核和公开核验分别记录，结果不明时先核对，不重复发送。

平台目录有 36 项目标，不等于全部自动发布。**安装包能力以对应发行版本的说明和当前账号状态为准**，不能用 beta.5 源码说明替代 beta.3 的验收。公众号完整自动发布、其他待验收渠道、客户模型的真实文章质量仍未全部完成。

## 更新和资料

先保存内容并正常退出旧版，再打开适合自己系统的新版。同一系统用户的桌面预览使用 GuanyinGEO-Desktop-Preview 资料目录；不要把密钥、令牌、登录会话或个人数据上传 GitHub。不同浏览器与桌面应用不自动共用登录。

本地 beta.5 已加入六类 API 账号的一次定时发送，正常重启保留未执行计划，错过到点后 2 分钟不补发；仅代码与隔离测试通过，真实到点发送及新安装包以最终回执为准。它不扩展 beta.3 安装包的能力。

当前 beta.5 的完整 ZIP 备份包含文章配图和附件原件，资料 JSON 不能代替它。完整 ZIP 用于原工作区恢复，需要原工作区验证信息；仅拷贝 ZIP 到新电脑不等于完成迁移。具体更新与恢复以该包的使用说明为准。
