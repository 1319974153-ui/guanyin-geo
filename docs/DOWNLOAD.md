# 下载与使用

当前公开版本为 **0.49.0-beta.6 桌面预览**。在 GitHub 发行页选择对应系统的 ZIP，可同时下载 SHA-256 校验文件。

- Apple Silicon Mac。完整解压后打开“观引桌面预览.app”。预览包未做 Apple 公证。
- Windows x64。完整解压后双击“启动观引.cmd”。本包已通过静态校验，真机验收待完成。

随包提供应用运行时。使用本机写作时，可在“AI 写作模型”里选择电脑上 Ollama 已安装的文本模型。也可配置自己的云端模型。

[GitHub 发行与校验文件](https://github.com/1319974153-ui/guanyin-geo/releases/tag/v0.49.0-beta.6)

## 开始使用

1. 填品牌名称与介绍，补充允许公开的真实资料。
2. 在产品内配置自己的文本模型，查看并确认调用费用后生成文章。
3. 审核内容，在观引内登录已支持的平台，勾选可执行的账号发送。
4. 查看每个平台的原稿与结果；草稿、提交、审核和公开核验分别记录，结果不明时先核对，不重复发送。

平台目录有 36 项目标，不等于全部自动发布。**安装包能力以对应发行版本的说明和当前账号状态为准**。公众号完整自动发布、其他待验收渠道、客户模型的真实文章质量仍未全部完成。

## 更新和资料

先保存内容并正常退出旧版，再打开适合自己系统的新版。同一系统用户的桌面预览使用 GuanyinGEO-Desktop-Preview 资料目录；不要把密钥、令牌、登录会话或个人数据上传 GitHub。不同浏览器与桌面应用不自动共用登录。

本版支持六类 API 账号的一次定时发送，正常重启保留未执行计划，错过到点后 2 分钟不补发。真实平台到点发送仍待验收。

完整 ZIP 备份包含文章配图和附件原件，资料 JSON 不能代替它。完整 ZIP 用于原工作区恢复，需要原工作区验证信息；仅拷贝 ZIP 到新电脑不等于完成迁移。具体更新与恢复以该包的使用说明为准。
