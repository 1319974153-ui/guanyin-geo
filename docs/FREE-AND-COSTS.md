# 免费范围和第三方费用

本项目自有源码采用 MIT 许可证，免费获取、学习、修改和自行运行。第三方组件保持各自许可证；许可证不授予他人商标、账号或媒体素材的使用权。

“免费开源”不表示所有外部服务免费。模型 API、AI 图片/视频/配音、托管、存储、代理、付费媒体素材和平台服务可能另行收费，使用者自行申请账号并承担费用。本项目不提供共享 API Key，不承诺永久免费托管，不承诺收录、AI 引用、排名或收益。

默认使用自己的空工作区。没有配置外部服务时，不应宣称已经获得外部生成或发布能力。

## 简单模式的一篇稿件

查看内容计划免费。客户选择自己的模型并勾选费用确认后，一批最多发起一次写稿、一次质检；失败不自动重试或隔日继续。资料、问题或模型变化后停止调用并要求重建计划。模型实际费用按供应商用量结算；两次请求并非固定价格。恢复已返回的结果不会重新调用模型。

该操作不会开启全局后台或周期任务，不会自动搜索消费者 AI，也不会自动公开发文。已有单独设置的高级周期任务须在任务页管理；单篇授权不替它们续期或增加授权。
