# r65 网络加载错误与登录状态分离

2026-10-28 实际通过观引阿里云窗口的 DevTools Network 看到 `https://developer.aliyun.com/article/new` 返回 `net::ERR_CONNECTION_CLOSED`，传输 0 B。同机不带登录态的普通网络请求收到 302 登录跳转。只能确认当前桌面窗口加载失败，不能据此认定用户未登录，也不能确定是 VPN、服务端或浏览器连接问题。

修复：只处理主文档网络错误，忽略子资源失败和正常取消跳转；错误信息仅包含白名单描述和数字错误码，不保存或回显登录中转凭据。观引显示连接异常并暂停等待，提供重试连接；用户主动重试原窗口，不新建稿件、不请求验证码。网络恢复和编辑器身份核对通过后继续原流程。

验证：登录、隔离窗口、原稿、前后端防重复与回执定向测试通过。当前运行版没有热替换或重启；真实阿里云草稿复核仍未完成。本轮未提交或发布任何新稿。

事件定义依据：[Electron webContents did-fail-load](https://www.electronjs.org/docs/latest/api/web-contents#event-did-fail-load)。
