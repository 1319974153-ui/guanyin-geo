# 博客园草稿接入验收合同

日期：2026-10-22。范围：观引自研免插件发布中心的下一平台接入。

## 客户流程

文章编辑页 → 博客园连接 → 输入博客地址名称、用户名、平台访问令牌 → 自动检查归属并保存 → 选择保存平台草稿并勾选账号 → 显示独立结果。无需 CSDN 付费同步服务、Chrome 扩展或反复点击核验。

## 实现边界

仅请求 `https://rpc.cnblogs.com/metaweblog/<博客名>`，使用官方 `blogger.getUsersBlogs`、`metaWeblog.newPost`、`metaWeblog.getPost`、`metaWeblog.getRecentPosts`。新稿写入明确 `publish=false`，不包含公开提交、修改或删除接口，不触发模型费用。

- 所有权必须由接口返回的博客地址确认；用户名不等同于博客地址名称。
- 令牌加密存储，前端与回执不返回令牌；平台错误只返回安全错误码，不回显平台原始错误正文。
- 固定 HTTPS 目的地、不跟随跳转；XML 解析拒绝 DTD、外部实体、重复/危险字段，限制体积及深度。
- 仅接受当前已审核真实稿件和有效事实版本；AI 声明保留。
- 写入前持久化原任务；按账号、品牌、稿件版本防重。取得平台编号后先落盘，再检查完整正文。中断后不重试创建。
- 查询中发现内容变化、多个匹配或找不到原稿时保留待处理。不凭 HTTP 200、标题或本地状态宣称成功。
- 公开发布未实现；没有真实访问令牌时，不以模拟接口结果宣称账号/草稿已实测。

## 验收层次

自动测试覆盖编解码、凭据隔离、账号归属、拒绝跳转、原稿全量比对、重复点击、断线恢复、权限与备份/品牌删除。

桌面最终包须确认连接入口、表单、平台选择与旧回执保留。真实平台另需由用户在产品内填入已有访问令牌；不得从浏览器提取登录 Cookie 或在聊天索取令牌。只有真实草稿回读通过后再更新实机验收状态。

## 依据

[博客园官方 MetaWeblog 接口](https://rpc.cnblogs.com/metaweblog/example)，2026-10-22 读取。接口支持并不代表用户账号已授权或已完成真实投稿。
