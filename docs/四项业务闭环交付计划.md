# 四项业务闭环交付计划

正式源码为当前仓库；在 `codex/guanyin-user-journey-fixes` 延续上一轮修复，不另造平行产品。

目标用户：自己安装观引的业务运营人员。数据、平台账号与模型额度由使用者拥有。产品不要求 Codex 运行。

按顺序交付并复验：

1. 真实元宝采集向导：选择问题版本和实际模式，打开平台、复制固定问题，保存原文/引用；从已有记录发起同条件复测，服务端拒绝伪装成同条件的不同采样。
2. 发布闭环：审核稿直达平台交付，区分直接执行与人工发布，保存真实回执与公开 URL，分别进入网页检查和 AI 实测；不自动编造平台状态。
3. 普通用户启动包：随包提供运行时和构建产物，双击启动/停止/诊断；每份安装独立数据；从中文空格路径干净解压，验收重启、冲突与安全清理。Mac 完成实机验收；Windows 只有实际运行过才标记通过。
4. 试用隔离、费用预算、权限：演示记录不能进入正式指标；服务端预算控制付费请求并保存用量；用不同身份及品牌测试读取、写入、导出、任务和凭据边界。

发布包不包含生产数据库、API 密钥、浏览器会话或开发绝对路径。真实平台需要用户账号的操作保留在人机交互中；向导可用不等于元宝已推荐，公开 URL 可访问不等于收录。
