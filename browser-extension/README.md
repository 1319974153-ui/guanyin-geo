# 观引发布连接器 0.2.0（多平台验收版）

观引自有实现，不依赖 CSDN 的付费同步服务。包含 CSDN、头条、知乎、抖音图文和小红书图文的独立账号连接、编辑器适配、任务队列及回执检查。

**当前是开发验收版，四个新增平台尚未通过真实账号的完整发布验收。正式自动提交默认关闭。代码和模拟测试通过不等于平台已经可用。**

## 能力与验收范围

| 平台 | 本轮实现 | 真实平台证据 |
| --- | --- | --- |
| CSDN | 账号、正文填入、提交保护、成功页解析 | 0.1.4 已核验身份和标题正文填入；标签、声明、最终发布待验收 |
| 头条、知乎 | 独立连接、标题正文填入、发布预检、一次提交与回执解析 | 新适配器尚未真实运行验收 |
| 抖音、小红书 | 图文账号、图片上传、标题正文、发布预检、一次提交与回执解析 | 新适配器尚未真实运行验收；不包含视频发布 |

平台草稿保存尚未为这些浏览器适配器开放。“填入编辑器”不能当作平台草稿保存成功。审核通过、公开可访问须独立确认。

## 安装与连接

1. 使用本批隔离验收版观引和此版本扩展。已有正式安装包尚未包含这些修改。
2. 用户在 Chrome 扩展管理页加载本目录；从旧版升级需重新加载并确认版本 0.2.0。
3. 在观引“浏览器发布连接”选择平台、生成配对信息；扩展选择同一平台并粘贴配对。每个平台单独配对，保留原 CSDN 连接。
4. 扩展打开对应编辑器，用户完成登录，点击核验账号。网页无法提供唯一身份时会停止，不猜测账号。
5. 在观引写稿、选择已核验账号、核对正文后发送。抖音和小红书必须附图：本版本最多 9 张，单张 2 MiB、合计 8 MiB，PNG/JPEG/WebP；这些是本产品验收限制，不代表平台官方上限。超出正文限制时拒绝发送，不悄悄截断。

## 权限与数据

权限仅 storage、scripting、alarms；无 cookies、history、all_urls。仅在用户操作时申请所选平台域名：

- 本机连接：`http://127.0.0.1/*`，协议另行绑定实际端口、实例和一次配对凭据。
- CSDN：`https://mp.csdn.net/*`
- 头条：`https://mp.toutiao.com/*`
- 知乎：`https://zhuanlan.zhihu.com/*`、`https://www.zhihu.com/*`
- 抖音：`https://creator.douyin.com/*`
- 小红书：`https://creator.xiaohongshu.com/*`

新增域名需用户明确授权；不读取或导出平台 Cookie。令牌保存在扩展可信上下文，本机仅保存令牌哈希。稿件图片只在明确发送后进入本实例的发布队列和相应平台；队列文件含用户正文和图片，不可公开打包。

## 中断与发布状态

- 账号、正文、图片变化都会生成新指纹并重新确认，旧 CSDN 去重记录兼容保留。
- 编辑器已有正文或图片时停止，不覆盖用户已有草稿。
- 单次提交前持久化记录；提交后超时标记结果未知，禁止自动重发或调用备用写接口。
- 只有实际平台文章链接和对应 ID 才能作为提交回执，创作中心主页不算回执；有回执仍不等于公开审核通过。
- 关闭浏览器或本机服务会停止工作，不是云端定时发布服务。
- 验证码、协议、登录由用户处理；AI 声明等必要表单无法确认时停止。
- 单平台验收开关 `GEO_SOCIAL_PUBLISH_PLATFORMS` 只用于完成账户/排版核验后的专用验收环境，默认空。旧 `GEO_SOCIAL_PUBLISH_EXPERIMENTAL=1` 仅影响 CSDN。未完成真实验收不得作为正式包开启。

## 0.2.0 更新

新增四平台隔离连接、媒体完整性校验、同稿多账号分发、平台 URL 归属检查和逐平台提交开关。自动测试采用模拟 Chrome 和编辑器，不能替代真实平台验收。参考来源及许可证见 `REFERENCE_NOTICE.md`。

## 0.1.1 启动修复

移除 Chrome Service Worker 不允许的顶层 await，事件监听同步注册，存储保护异步完成后才处理业务。新增构建检查禁止入口及依赖出现顶层 await。

## 0.1.2 账号识别修复

工具栏头像链接只有空白文字时，先清理空白，再依次使用链接标题或已验证的账号 ID 作为显示名，不生成或猜测昵称。账号身份仍以同一个工具栏主页链接核验，不放宽服务端证据检查。

## 0.1.3 诊断修复

页面操作异常通过显式错误对象传回扩展；空结果不会继续登记账号或领取任务。服务端显示失败字段名称，不回显凭据或提交内容。仍须完成真实账号和填稿验收。
