# 观引发布连接器 0.1.0（验收版）

当前版本：配对、登录身份读取、固定稿件队列、CSDN 富文本编辑器填入、单次提交保护与成功页回执解析已实现。**尚未完成真实 CSDN 账号验收，不能称为可用的一键公开发布产品。** 普通启动只开放填入编辑器，最终发布开关默认关闭。头条、知乎尚未接入。

## 安装与连接

1. 启动同包中的观引，建立自己的品牌/个人 IP。
2. Chrome 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选择本文件所在 `browser-extension` 文件夹。本包未上架商店，安装须由使用者明确确认。
3. 观引“模型与账号” → “浏览器发布连接” → “连接 Chrome”；复制配对信息，粘贴到扩展，点击连接。配对信息仅 5 分钟有效，请勿发给他人。
4. 扩展“打开 CSDN 并登录” → 本人完成登录 → “核验当前账号”。回到观引刷新账号，选择已审核稿件和标签后发送到编辑器。

权限：首次连接按需申请 `http://127.0.0.1/*`；首次打开 CSDN 按需申请 `https://mp.csdn.net/*`。Chrome 主机权限无法按端口细分，观引协议另行限定完整端口、实例和一次配对凭据。没有 all_urls、cookies、浏览历史权限；没有常驻全网站内容脚本。允许在明确创建的 CSDN 编辑器标签执行填充，平台 Cookie 不读取、不上传到观引。

## 状态与中断

- 已配对不代表已登录，已登录不代表已发布。
- 已填入表示正文进入编辑器；已提交表示观察到 CSDN 实际成功页，仍不是审核通过或公开可访问。
- 稿件、账号或品牌改变后停止执行；编辑器已有内容时不覆盖。
- 提交前持久化执行状态，断线或超时后不重复点击，不调用备用写接口，不删除平台稿件。
- 在观引撤销连接使令牌失效。已开始提交的任务须到平台核对，不能承诺撤回已经发生的提交。
- 浏览器/本机服务关闭时暂停；重启不重放队列。未提交任务需在观引重新授权，已提交结果未知的任务只能核对回执。
- 浏览器凭据保存在扩展的可信上下文存储；本机仅保存配对令牌哈希。Cookie 留在 Chrome 自身。
- 连接和队列存放在本实例的数据目录 `publisher.sqlite`，不进入普通品牌备份。恢复工作区/删除品牌时撤销连接，业务备份不迁移浏览器授权。

## 实际验收边界

自动化测试使用内存数据库、模拟编辑器和模拟 Chrome API，不能代替平台验收。真实验收应先配对、核验唯一账号、用获准稿件确认排版及标签，最后才在单独的验收实例打开 `GEO_SOCIAL_PUBLISH_EXPERIMENTAL=1` 执行一次明确授权的投稿。没有这一步，不开放正式产品的一键提交。验证码、账号协议和登录由本人处理。

代码独立实现。编辑器选择器与流程参考 MIT 项目 [Omnipub](https://github.com/addozhang/omnipub)，平台网页升级后须重新验证；未把其内部接口当作平台官方发布 API。见 `REFERENCE_NOTICE.md`。
