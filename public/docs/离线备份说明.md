# 完整离线备份与恢复

适用版本：观引 GEO 0.23。入口：设置与完整功能 → 团队与数据。仅工作区所有者可操作。

## 导出内容

先创建云端恢复副本，再点击“完整 ZIP”。包内含业务快照和业务表记录、所有知识库文档版本的原始文件、带段落/页码信息的抽取全文，回答附件与固定回答快照，以及服务端签名校验信息。采用 JSZip 3.10.2，许可证随站点发布。

“资料 JSON”只导出业务记录与附件路径，不包含原始文件字节，不能单独恢复已丢失的附件。“完整 ZIP”遇到缺失或摘要不符的附件会停止，不会生成缺少附件却显示成功的备份。

不包含模型密钥、API Key、回调目的地及签名密钥、成员授权、站点配置、代码或数据库基础设施。原件内自行写入的敏感信息不会被自动移除。ZIP 本身未加密，请保存在可信位置；签名用于校验来源和完整性，不提供文件内容保密。

## 导入与恢复

1. 选择该站点、该工作区导出的完整 ZIP，查看品牌、问题、文档和附件数量。
2. 点击“校验并导入恢复副本”。服务端核验工作区签名、清单、每个附件的长度和 SHA-256 摘要；浏览器同时校验 ZIP 路径、目录、长度和 CRC。
3. 每个附件独立上传，进度保存在服务端。网络中断后重新选择同一份 ZIP，可跳过已确认上传的文件。请勿重新压缩、编辑或改写包内文件。
4. 全部上传完成后，事务保存为“离线导入”云端恢复副本。此时当前业务数据没有改变。
5. 在云端备份表选择对应副本恢复。现有恢复流程会保护当前数据，并核对当前版本，防止覆盖另一页面的新修改。

兼容 0.22 导出的旧包。新导入的附件使用当前工作区的新路径，不依赖原来的附件仍然存在。旧文档与新文档的版本关系保留。恢复后任务暂停；已有调用用量不会回退，不确定的调用不会自动重复。回调配置保持暂停，恢复历史不会自动向外重发。

## 范围与限制

- 仅支持同站点、同工作区；不是跨客户、跨站点迁移工具。服务端原加密密钥必须仍可用，密钥更换后旧包不能直接通过签名验证。服务密钥不放入 ZIP。
- 清单最多 12 MiB，单个附件最多 8 MiB，附件总量最多 160 MiB，最多 2048 个附件对象；原件和抽取全文各占一个对象；每份回答证据的附件和上下文快照也分别计数。ZIP 文件最多 180 MiB。超限时明确失败，不截断内容。
- 每个工作区最多保留 3 个未完成的暂存导入，24 小时内有效；成功上传会延长有效期。到期后可点击“清理暂存”，不是自动清理。清理失败可以重试。
- 云端恢复副本保留最近 10 份。附件自动回收、异地定时备份、跨站迁移和更大规模归档仍待实现。
- 浏览器需要有足够内存读取完整 ZIP。大文件请在桌面浏览器处理。

当前已有真实 ZIP、SQLite 事务和模拟对象存储的自动恢复测试，覆盖原件丢失后重建、全文版本、损坏/跨工作区拒绝、网络断点、数据库失败回滚和清理重试。正式账号下的真实业务文件恢复仍需验收，自动测试不替代该结果。

实现参考：[Cloudflare R2 Worker API](https://developers.cloudflare.com/r2/api/workers/workers-api-reference/)，用于附件存储与批量清理。
