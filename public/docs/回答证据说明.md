# 回答证据与公开搜索过程

观引 GEO 0.38。入口：任何“查看原回答”页面 → “添加截图 / 公开过程”或“查看证据记录”。

## 日常操作

1. 在“问题与回答 → 导入回答”保存实际取得的全文与引用。独立选择 Web/App 入口、提问时的问题版本，照录平台实际模式，填写地区/语言；未知地区或模式填“未记录”，未展示模型留空。可一起保存回答链接和公开搜索过程。保存后可直接查看原记录；网络中断时保持内容不变重试，不会重复计数。
2. 在回答详情添加截图或附件；可同时填写回答分享链接、平台公开显示的检索词、过程摘要和证据说明。没有附件时，也可单独保存公开过程。
3. 填写真实采集时间后保存。每次保存固定当时的回答全文、问题/产品范围、引用清单、平台/模式和可用模型信息，并保存提交者与服务器接收时间。
4. 通过证据记录查看原始快照、下载原件或快照 JSON。当前回答后来改变时会提示不一致；修改审核标签不会改变原文快照。

附件由提交者提供。文件摘要证明与保存时的字节一致，不证明截图未被编辑，也不证明平台真实推荐或引用。保存证据不会自动改变推荐/引用审核标签；不会把模型 API 回答改称消费端实测。只记录公开可见的搜索词和过程，不获取或推测隐藏思维链。

## 文件与权限

支持 PNG、JPEG、WebP、PDF、UTF-8 TXT/Markdown。单个附件最多 8 MiB，每条回答最多 20 份证据，整个工作区的回答附件与快照合计最多 100 MiB。快照正文最多 200 KB。公开检索词最多 30 条、每条 200 字，过程摘要最多 20000 字。证据暂不提供单条删除，以保留追溯；品牌整体清理沿用删除前备份流程，容量回收仍待完善。

所有者、管理员和该品牌编辑可上传；获授权的审核人及只读成员可查看和下载。服务端逐次检查工作区及品牌权限。原件强制作为附件下载，不作为网站脚本运行。文件大小、扩展名/基本签名、摘要和路径均检查；这不是防病毒扫描或截图真实性识别。

提交中断时保持表单内容不变重试，沿用同一请求编号，可找回此前成功保存的记录。修改内容后重用同一编号会被拒绝；重新打开表单才能保存一份新证据。并发编辑回答会阻止把附件错绑到新原文。

## 报告与备份

报告归档固定本期及可用前期回答的证据索引，保留证据编号、回答编号、时间和文件/快照 SHA-256 摘要；不把文件字节直接塞入 Markdown。授权用户可在回答详情取原件。

“完整 ZIP”同时导出附件与上下文快照；离线导入后重新关联本工作区的新存储路径。仅工作区 JSON 或报告 Markdown 不包含附件字节。恢复限制见 [离线备份说明](离线备份说明.md)。

## 授权接口

已有获授权采集器可使用下列接口。私有站点仍需 Sites 服务访问授权，另外使用限品牌的应用 Key；不得用执行器凭据替代。

- `GET /api/v1/answer-evidence/list?answerId=...`：读取记录及当前 `answerHash`，需要 read 权限。
- `POST /api/v1/answer-evidence/upload`：multipart/form-data，需要 write 权限。字段：稳定 UUID `id`、真实 `answerId`、上一步 `answerHash`、ISO `capturedAt`；可选 `file`、`sourceUrl`、`note`、逐行 `searchQueries`、`processSummary`。附件或公开过程至少一项非空。
- `GET /api/v1/answer-evidence/context?id=...`：读取固定回答快照和是否仍与当前原文一致，需要 read 权限。
- `GET /api/v1/answer-evidence/download?id=...`：下载原件，需要 read 权限。

接口仅保存调用者实际提供的内容，不会自动登录第三方平台、采样或截图。当前已验证本地 SQLite/对象存储、API 权限、ZIP 恢复与前端回执流程；正式消费端业务样本和平台自动采集仍待验收。
