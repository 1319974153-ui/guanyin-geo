# 报告档案库 · 0.36

在「效果报告」底部管理固定报告。标题、数据类型、归档方式和生成日期筛选只查找已有档案，不生成新报告，也不调用模型。

- 每页 20 份，可前后翻页。新归档不会打乱正在读取的后续页；刷新回到第一页可查看新增报告。
- 单次归档、周期周报、周期月报分别筛选。日期为 UTC 生成日期，不是报告统计窗口。
- 勾选本页最多 20 份后点击导出，下载 JSON 包；每份含完整固定数据和 Markdown、原始回答与引用、附件索引。原件请另存完整离线备份。
- 批次原文上限 4 MiB、导出上限 8 MiB。超限时减少选择，不输出不完整的部分成功包。
- 只有所有者和管理员可删除。先查看所选标题与时间，输入「删除 N 份报告」。原文发生变化会要求重新核对。
- 删除只清空选中报告的快照正文、释放有效报告额度；保留编号、标题和删除回执。原始回答、已有备份、外部已发送的通知保持不变。没有单份撤销，恢复旧备份会影响整个工作区，请谨慎操作。
- 删除自动周报/月报后，相同计划、筛选和周期不重建；下一周期继续。删除回执保存在业务备份中。恢复删除前的备份可恢复报告，但需要单独确认完整工作区恢复。

## 授权接口

`GET /api/v1/reports?brandId=…` 支持 `q`（标题文字）、`surface=api|import`、`kind=manual|weekly|monthly`、`from`/`to`（UTC 日期）、`limit`（1–50）、`cursor`。响应含 `reports`、`total`、`nextCursor` 和当前授权范围的容量信息。下一页原样传回 `nextCursor`，不要自行改写。筛选或页大小改变后清空游标。

`GET /api/v1/reports/export?brandId=…&ids=…` 的 `ids` 为 URL 编码的 JSON 数组。必须整批属于授权品牌；缺失、重复、越权或超限直接返回错误，不返回部分客户资料。

`GET /api/v1/reports/snapshot?id=…` 读取固定档案；已删除档案返回 410，未授权返回 404。MCP `geo_list_reports` 复用相同筛选与游标，`geo_get_report` 保留分段读取的内容摘要。

删除仅支持登录的所有者/管理员在工作台操作；API Key 和 MCP 无删除能力。浏览器删除预览绑定所选报告全文摘要，提交使用固定请求编号。响应丢失后重试相同编号可恢复既有回执，不重复删除。

## 验证范围

自动测试覆盖超过 50 份的翻页、同时间排序、新增档案、特殊字符标题、日期/类型过滤、原文完整性、容量、权限、事务回滚、请求丢失恢复、旧编号防重建、周期计划、备份恢复、跨客户迟到响应和官方 MCP 客户端。删除流程未在生产中清理真实客户报告。
