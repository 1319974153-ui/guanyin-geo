## 已实现的保存流程

1. 问题与回答 → 导入回答 → 选问题和实际提问版本。
2. 来源平台、入口（Web/App）与模式分别填写。模式直接照录页面；不再强制归类成“联网标准/深度”。地区未知填“未记录”，模型未展示留空。
3. 保存原始全文、实际引用、精确到秒的采样时间、语言；可填实际回答链接及公开检索过程。
4. 推荐与引用默认未核对；文本提及不会自动改成推荐。
5. 同一表单保持稳定采集编号。断网后保持内容不变重试会找回原记录。编号对应了不同原文、模式或上下文时拒绝覆盖；原文保留空格和换行。
6. 保存后添加证据时自动带入回答的采样时间与来源链接。报告与工作区导出包含采样上下文。

授权 API `POST /api/v1/answers` 同样保留这些字段。`externalId` 必填；`model`、`sourceUrl`、`dateZone` 可选；`recommendation` 可为 unknown/no/yes，默认为 unknown。引用只接收有效 HTTP(S) URL，不接受含用户名密码的链接。采样时间要求带时区，最多允许 5 分钟设备误差；无正文、非法历史版本及超限输入被拒绝。
