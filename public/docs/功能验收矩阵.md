# 观引 GEO 功能验收矩阵

当前版本 0.49.0-beta.5，更新于 2026-11-13。**开发预览，完整产品验收未结束。** 下表为 36 项产品模块，与发布中心的 36 项平台和内容形式目录是两套范围。

“已实现”表示代码具备对应流程；“隔离测试”只验证受控输入和本地操作；“真实平台验收”限记录中的账号、动作、内容形式和版本；“最终包验收”必须重新核对本次实际安装包。四者不能互相代替。旧通过记录不自动授权当前账号发布。

本地源码为 beta.5；公开下载仍为 beta.3 Mac。第六批曾保存 beta.5 隔离预览包，不包含此后的全部改动。单次定时发送代码与隔离测试已完成，真实平台到点发送及本轮 Mac/Windows 新包仍由最终交付回执裁定。Windows 真机、客户模型真实质量和未完成平台验收仍待完成。
