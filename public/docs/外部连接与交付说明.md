# 外部连接与交付

版本 0.46.0，2026-10-12。

## 交付与连接

左侧「交付与连接」集中已有执行入口，并新增站长回执、跨品牌汇总、审核稿发布包。功能可用、账号可用、提交成功、发布成功、实际收录、AI 引用是不同里程碑。

站长回执按 Google / Bing / 百度、所有权 / 抓取 / 索引申请 / 实际收录 / 站点地图分别保存。必须保存平台原文、实际观察时间和官方来源链接。历史追加保存，不覆盖之前的失败。不自动登录站长平台，不把访问成功推断成收录。每品牌显示最近 200 条，工作区最多 2000 条；完整历史随已有工作区备份保留。

跨品牌汇总按服务端成员品牌权限过滤。展示题集覆盖、有效回答、提及分母、待审核稿、发布和平台审核数量。模型 API 与消费者实测分开；没有共同题集时不计算跨品牌综合排名。

## 发布包与本机抖音适配器

「审核稿多平台发布包」只导出当前已审核且依据未失效的稿件，保留正文、事实版本、摘要、审核时间与四个平台入口。不自动裁剪长文，不把导出记为发布。

本机适配器使用已安装的 social-auto-upload（SAU），不读取 Chrome 登录文件，不把 cookie 上传到网站。运行环境需 Node.js 与 SAU；专用账号须本人扫码。账号登录有效只证明连接，不能证明平台发布成功。

维护者命令（普通用户无需执行）：

```
sau douyin login --account wenshu-geo --headed
sau douyin check --account wenshu-geo
node tools/social/douyin.mjs 审核稿发布包.json wenshu-geo 本机回执目录 /绝对路径/封面.png
```

默认仅检查参数。明确发布时增加 `--publish-confirmed`。仅接受 24 小时内导出的原包；标题最多 30 字、正文最多 1000 字，需预先审核适合图文的版本。支持 1–35 张图片。登录无效就停止，提交前建立独占回执文件，结果未知不自动重试。即使命令正常结束，也标记为「需核对回执」，由助手核对平台审核状态、作品与链接后登记。不要删除本机提交记录来绕过重复保护。

当前本机适配器不是云端无人值守发布服务，未纳入通用后台 tick，不会因开启报告而自动发布文章。知乎与头条号没有已验证的 SAU 适配器；百家号、知乎、头条号保留浏览器辅助发布与真实回执。各平台实际发布仍需账号、平台权限、封面与声明验收。

## 消费者采样与已有后台

消费者采样目前通过助手操作消费者界面并保存真实原文/引用/截图。没有接入可独立运行的消费者浏览器采样服务；后台 API 模型任务不能代替它。安全验证和本人登录交给用户完成，不尝试绕过。

周月报、网页复测、备份已有后台执行器。电脑休眠、离线时延后，不能宣称全天在线。已停止的 tnyma 计划不会因本次更新恢复。
