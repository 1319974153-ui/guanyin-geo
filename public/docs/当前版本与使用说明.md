# 观引 GEO 0.49.0-beta.5 · 当前版本与使用说明

更新：2026-11-15。当前 GitHub 下载为 **0.49.0-beta.6 桌面预览**。本机写作可连接 Ollama 已安装的文本模型。Mac Apple Silicon 与 Windows x64 的验证范围见发行说明。

观引把品牌资料、AI 写作、平台发布与 GEO 诊断放在一起。个人、产品和企业统一使用“品牌”；界面以“工作台、文章与发布、GEO 诊断”为主，详细设置按需展开。

## 日常怎么用

1. **填一次品牌资料。** 填写名称和一句介绍，再补入真实案例、产品资料与出处。确认哪些允许公开，内部资料单独保留。
2. **连接自己的模型。** 在产品里配置文本模型和密钥。先查看本次计划与费用范围，再决定是否生成。
3. **让 AI 写文章。** 选择想解决的用户问题和通用目标，AI 提供几个方向；选择后生成草稿。查看检查建议，可让 AI 改稿或按目标平台改一版，原文与历史保留。
4. **登录、勾选、发送。** 首次在观引内登录已接入平台。审核当前稿件后勾选可用账号，选择保存平台草稿或公开提交；每个平台分别显示结果。
5. **看真实效果。** 保存消费者 AI 的回答、时间、模式和引用，再查看诊断、补证建议与下一步行动。没有样本时显示不足，不自动补出推荐率。

本机桌面版无需安装 Node、Codex 或浏览器插件。它保存当前系统用户的资料与平台会话；平台登录过期或要求扫码、短信时仍需本人完成。Chrome 登录和观引独立窗口的登录不自动通用。本机同一实例共用一个工作区；配置真实登录身份的托管版才提供团队身份与权限隔离。

## 文章质量与费用

- 通用目标包括：提升品牌认知、突出优势与特色、建立信任、解答用户疑问、帮助比较与选择。具体题目由当前品牌资料、问题和依据决定，不固定套用某个行业。
- 问题旁可展开查看来源，区分手工录入、规则建议、文件导入和模型建议。建议问题不代表真实搜索量，也不是模型检索概率排名；没有来源的旧问题如实标记。
- 写作只采用当前有效、已确认且允许公开的事实。检查关注回答是否完整、标题承诺是否兑现、类型是否契合、宣传是否重复、事实是否有依据。检查辅助审核，不代替真实客户验证。
- 可以一次确认整篇写作的有限调用额度，覆盖方向、首稿、质检和改稿各一次；每一步仍由用户点击执行。超出范围、更换模型或资料变化后重新确认，不每天自行调用。
- 真实模型的文章质量评测尚未完成。本地模拟服务的界面测试，只能证明操作与恢复流程，不是实际成稿质量或模型效果证明。

## 配图和平台适配

在文章内展开“配图”，从电脑添加或复用本品牌图片。最多 9 张，单张 2 MB、合计 8 MB；本地保存时可以暂不确认对外使用，发布前需确认该稿图片的使用权。图片与顺序随稿件保存，修改后需重新审核。

平台预览会检查标题、正文、摘要、标签和图片的已知条件。不会静默截断正文，也不会丢掉图片后当纯文字发送。不确定的平台规则会保留待确认提示；预览通过不代表平台已经接受文章。

## 哪些平台能发

目录包含 **36 项平台、内容形式和通用接口目标，不代表全部支持自动发布**。当前账号、目标动作和稿件条件仍以发布面板为准。

- 历史公开动作验收记录包括：已绑定的个人官网、知乎、博客园、腾讯云、51CTO、抖音图文。它们有各自的账号、文章形式、版本和验收范围，不保证新的客户账号或图片稿自动通过。
- CSDN、掘金、阿里云等有历史平台草稿记录；这不能替代公开提交验收。其他只有适配代码或目录入口的平台，仍须分别验收。
- WordPress、Typecho、MetaWeblog、语雀等需要客户自己配置有效网站或接口授权；代码测试不能代替真实网站兼容性验收。
- 微信公众号的草稿、发表与真实回执仍未完成验收；公众号、百家号既有后台访问限制保留，不能换路径绕过，也不会作为已完成能力交付。
- **单次定时发送代码已完成。** 首版用于已连接的 WordPress、博客园、Typecho、MetaWeblog、个人官网和语雀 API 账号，限当前审核通过的无附加图片稿件；社交平台尚未开放定时。选定账号与一次时间后明确批准，保持观引运行。正常退出再打开会保留未执行计划，到点超过 2 分钟不补发；修改原稿、账号变化或从备份恢复后停止旧许可。已开始但结果不明的发送只核对、不重发，也不调用模型。隔离测试与真实平台到点发送分别验收，真实定时发布和最终包结果以本批回执为准。

## 发布结果怎么理解

- **已登记／准备中：** 已保存本次意图，尚不代表平台收到。
- **草稿已保存：** 平台已有对应非公开稿件。
- **已提交／审核中：** 已取得提交依据，等待平台审核或公开核验。
- **发布成功／公开已核验：** 达到该渠道规定的回执与公开证据条件。
- **需要处理／结果待确认：** 保留原任务，先核对原稿；不会因断网自动再发一遍。一个平台失败不应被汇总成全部成功。

平台发布、搜索收录、AI 引用、主动推荐是不同结果。观引帮助整理与验证，不保证行业排名或被首位推荐。

## 诊断与下一步

诊断将消费端真实回答、模型 API 结果和演练分开统计。报告显示已有依据、覆盖缺口、建议补充的案例或外部原文，以及如何完成核对。建议可加入改进待办，沿用原问题与采样条件再复测；完成材料不等于已经获奖、刊登、收录或被推荐。

报告可导出与归档；PDF 适合阅读，完整原始记录另行下载。自动取得所有消费者平台回答、持续联网排名和全行业权威榜单仍未完成。

## 备份、更新与恢复

在“设置与完整功能 → 备份与恢复”创建副本并下载 **完整 ZIP**，保留稿件图片和附件原件。“导出资料 JSON”只包含资料和图片引用，不能代替完整附件备份。

完整 ZIP 使用原工作区验证信息恢复，不包含模型密钥或平台登录会话，不能仅凭 ZIP 在一台全新电脑直接迁移。恢复图片稿会清除旧审核并要求重新确认使用权；历史平台回执保留，旧发送许可不会自动复活。

桌面升级会在启用后台任务前检查并备份已有业务数据。正常退出后再更新；启动失败的恢复、最终安装包与 Windows 真机结果以对应交付回执为准，不把源码测试当成安装验收。
