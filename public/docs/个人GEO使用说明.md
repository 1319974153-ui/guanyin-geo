# 个人 GEO 使用说明

用独立的个人资料条目管理本人信息，不与产品品牌混用。姓名、身份、项目职责、账号和可公开程度需由本人确认；只有资料已存在并有依据，才生成介绍或案例。

1. 在品牌管理中建立本人的独立条目，登记姓名和个人网站。产品关系尚未确认时，不写创始人、负责人或团队成果。
2. 在知识库上传本人确认的介绍与案例记录，标明来源和时间。代码检查报告不是搜索引擎抓取或 AI 引用证据。
3. 在问题管理导入候选问题，分别标注身份、来源和自然需求。导入问题不会创建采样任务；检测需另行授权。
4. 内容创作优先整理真实过程：背景、分工、步骤、产出、问题与限制。保存事实版本和生成依据，稿件仍需核对。
5. 在网站诊断生成 Person / ProfilePage 标记。姓名必须明确填写，职业等可留空；只登记本人控制的真实账号。下载标记后放在相应介绍可见的网页中，不会自动安装到网站。
6. 发布管理分别记录草稿、审核、上线回执与公开 URL。自有 WordPress 可使用已授权连接和封面上传；其他社交平台仍需按其实际授权条件操作。
7. 收录、AI 引用、自然推荐和咨询均需要自己的证据。消费者界面与模型 API 回答分开，未知不填成零效果。

温舒本轮消费者搜索检测保持停止。未配置助手连接时，不把已准备的本地资料包说成已导入工作台；也不复用其他执行器凭据或修改工作台访问范围。当前网站只展示已发生的网站建设与内容工作。
