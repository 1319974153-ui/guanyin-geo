# 需求来源数据 API

使用工作区管理员已有权限创建的应用 Key；私有 Sites 访问授权与应用 Key 分开配置。不要把凭据写入 URL。此接口不自动抓取外部数据、不替用户取得数据许可，也不调用模型。

所有请求绑定 `brandId`。`GET /api/v1/demand?brandId=…` 返回最多 100 个批次摘要；`GET /api/v1/demand/detail?brandId=…&id=…` 返回完整批次、导入文本和 Markdown；`GET /api/v1/demand/compare?brandId=…&id=本期ID&previousId=前期ID` 返回逐行可比性和变化。需要 read scope。

`POST /api/v1/demand/preview` 和 `/api/v1/demand/import` 需要 write scope，JSON 请求字段如下：

|字段|含义|
|---|---|
|brandId|授权品牌 ID|
|id|导入请求 ID，16–80 位字母、数字或连字符；一份逻辑请求固定使用同一 ID|
|title|批次名称，最多 200 字|
|sourceFile|来源文件名，最多 200 字|
|format|csv、tsv 或 json|
|rawText|解码后的完整导入文本，最多 500000 字；整个 JSON 请求最多 1 MB|
|mapping|字段到原始表头的映射；keyword 必填，value 或 lower+upper 至少选择一组；from/to/questionId 可选；未映射用空字符串|
|metadata|下表中的来源口径|
|selected|import 必填，1–500 个预检返回的 ready 行号，无重复；preview 不需要|

JSON 文件内容需为平面字段对象数组，CSV/TSV 首行为唯一表头。每列只能映射到一个字段。keyword 最多 500 字；value/lower/upper 为有限非负数、最大 10^15，不自动解析千分位、百分号或小于号。行内 from/to 是 YYYY-MM-DD；未映射时使用默认窗口。questionId 只能属于当前品牌。

metadata 字段：

- sourceName、sourceUrl：来源名称和无用户名密码的 HTTP/HTTPS 说明地址。
- sourceType：official、licensed、first_party、other；仅为提供者登记类别。
- platform、region、language：明确的平台、地区、语言范围，不推定默认值。
- metric：volume、relative_index、impressions、clicks、other。
- unit、method：单位与完整统计/估算方法。
- normalizationId：relative_index 必填，相同归一化尺度的真实批次标识；不能随意用相同名称让不同尺度变得可比。
- observedOn、from、to：获取日期和默认窗口，YYYY-MM-DD；结束不晚于获取日期，获取日期不晚于今天。
- authorizationNote：来源依据和使用许可说明；此字段不等于独立授权认证。

先 preview，检查每行 status 与 note，再提交 selected。保存所有选中行和完整文本快照；无效选择整批失败。收到不确定响应时，保持原 id 和相同内容重试。不同内容重用同一 id 返回 409。导入后的更正应新建批次，并作废旧批次，原始数据不覆盖。

`POST /api/v1/demand/status` 接收 brandId、id、revision、requestId、status（active 或 void）、note。requestId 为本次状态操作的稳定 ID；同一 ID 不同内容返回 409，陈旧 revision 返回 409，最多 50 条状态历史。再次恢复是新操作，需要新的 requestId 和当前 revision。

GET 详情会包含所有导入文本列，请只授予需要读取这些资料的账号。批次保存在现有业务备份中，Key、许可和外部数据服务授权不随备份自动扩大。
