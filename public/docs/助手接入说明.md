# 观引 GEO 助手接入

在服务连接创建按品牌授权的 API Key，再连接页面中显示的 `/api/v1/mcp` 地址。支持 MCP 2026-07-28 和 2025 协议的 Streamable HTTP 客户端，使用官方开源 SDK 2.2.0。

私有站点仍有两层验证：`Authorization: Bearer <GEO_API_KEY>` 为品牌应用授权；`OAI-Sites-Authorization: Bearer <SITES_SERVICE_TOKEN>` 为站点服务访问授权。均在受信任的客户端保存，不写入网站地址。应用 Key 可以在工作台撤销或轮换；站点凭据由站点维护者配置。未连接真实外部助手前，不显示已连接。

| 授权 | 可用能力 |
|---|---|
| read | 品牌、题目、诊断、稿件及出处、任务进度、报告档案 |
| write | 固定报告归档；原开放 API 导入回答 |
| write + run | 创建并启用采样/写作任务、暂停/继续/取消 |

创建、恢复任务会让后台执行器自动运行并可能计费，既有模型日额度仍生效。只读查询及归档不调用模型。工具按每次请求的有效权限列出；撤销、过期和每日 API 配额继续生效。只授予 run 的执行器不具备助手业务读取能力。

创建任务/归档用稳定 `id`，重复提交返回原记录。新任务状态是入队，不等于完成。不会自动将稿件审核通过或发布到媒体。协议通知、查询及失败请求也可能计入 API 日额度。

稿件、问题和任务支持分页，报告 Markdown 支持分段。读取变动稿件时核对每段 `textHash`；发生变化需重新读取。事实快照只说明当时使用的资料，截断字段会明确标记。诊断最多附每项 30 个证据 ID，需要全部原文可读取固定报告。

可下载 Skill 包供支持本地技能的助手使用。解压后将 `guanyin-geo` 文件夹放入该助手的技能目录。随附 Node 客户端无需安装第三方依赖，配置方式见包内 SKILL.md。若客户端要求 OAuth 自动注册而不能配置服务访问头，目前需使用随附客户端；本版未提供 OAuth 注册或自动添加 ChatGPT 连接器。

接入验收：先只读列品牌并检查授权范围，再读取已有报告；需执行时使用已授权的小批任务，核对工作台中同一任务 ID。当前自动测试覆盖官方 SDK 新旧协议及本地业务数据库；真实生产密钥与外部客户端的首次登录仍需独立验收。

协议及 SDK 来源：[MCP 官方规范](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports)、[官方 TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk)。
