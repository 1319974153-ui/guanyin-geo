# 发布与平台回执说明

版本：0.43.0。

## 保存一条真实发布记录

1. 选择品牌和文章，确认标题。选择渠道后会填入入口；仍应核对平台实际登录账号，并填写昵称或公开账号标识。
2. 到平台编辑或发布后，按实际显示状态选择“平台草稿”“平台审核中”“平台审核未通过”“平台已发布”或“已下线”。这些状态是人工登记，须有回执地址或具体观察说明。
3. 后台草稿、审核、作品详情地址填入“平台回执地址”。若只有作品编号和状态文字，保存到说明中；不要把后台地址填进“公开文章 URL”。
4. 取得公开文章地址后，再补齐 URL。仅“已登记链接”和“平台已发布”且有可复测公开 URL 时才执行网页检查。
5. 查看引用时继续核对消费端原回答、引用地址和采集时间，区分模型 API 与 Web/App 实测。

## 状态含义

| 阶段 | 证据要求 | 网页复测 |
| --- | --- | --- |
| 待发布 | 可先建任务，无需声称已提交 | 不执行 |
| 平台草稿 / 审核中 / 审核未通过 | 回执地址或状态说明 | 不执行 |
| 已登记链接 · 上线待核对 | 公开文章 URL | 可执行，但不表示平台已发布或被收录 |
| 平台已发布 · 人工登记 | 回执地址或实际观察说明；公开 URL 可稍后补 | 有公开 URL 才执行 |
| 已下线 · 人工登记 | 回执地址或状态说明 | 不执行，历史检查保留 |

八个常用渠道：知乎、今日头条、抖音、小红书、百家号、搜狐号、微信公众号、B站。自动填入入口不代表登录、身份认证、平台授权或提交已经完成。

## 账号换错或作品被删除

保留旧作品回执和原账号，将阶段改为“已下线”，说明删除信息来源与时间。新账号重新发布另建记录，保存新的作品编号，避免把两次发布视作同一来源。用户口头告知删除和操作人实际看到删除，应在说明中明确区分。

## 检查结果与历史

URL、阶段、频率或窗口变化时，旧检查仍保留但标为历史结果；进行中的旧配置检查不覆盖新记录。已知创作后台和编辑器地址不会进入网页抓取。此识别只覆盖已列出的常见地址，不声称能识别所有平台登录页。

手工状态可由编辑人员登记，并非平台签名证明。WordPress 发布接口产生的回执字段继续只读。公开页面可访问、被搜索引擎收录、被 AI 引用和产生咨询分别验收。
