# 自有 WordPress 网站发布 · 0.44

入口：「发布与复测 → 自有 WordPress 网站」。支持客户已授权的自有 WordPress 网站；不自动注册网站，不替代知乎、头条、微信公众号等平台授权。

## 一次连接

管理员填写 HTTPS 网站根目录、网站用户名和专用 Application Password。安装在子目录的网站填写对应子目录。应用密码在 WordPress 用户资料页生成；不要使用日常登录密码，也不要将应用密码发到聊天、稿件或备注里。

连接密钥使用工作台服务端加密存储，读取接口与备份不返回密钥。保存后点击「验证连接」，读取当前账号的 `edit_posts` 与 `publish_posts` 权限。没有编辑权限不能使用；仅有编辑权限可建草稿，不能直接发布。每个品牌独立连接一个网站，更新网站地址必须重新填写应用密码并验证。暂停连接后停止新的外部请求。

依据：[WordPress 官方认证说明](https://developer.wordpress.org/rest-api/using-the-rest-api/authentication/)采用 HTTPS Basic Authentication 配合 Application Password；[文章接口](https://developer.wordpress.org/rest-api/reference/posts/)提供创建、读取和更新文章的能力。

## 从审核稿到网站

1. 在内容工作台完成稿件审核。
2. 在发布页选择「创建网站草稿」，核对目标网站、标题、排版预览和转换提示，再保存。提交的是当前已审核版本；标题自动带入。创建仅写入远端草稿。
3. 打开「稿件与回执」。核对内容后点击「发布到此网站」。工作台先读取远端标题与正文并检查本地稿件和事实快照；一致且仍为草稿时才请求发布。
4. 收到发布回执后，自动登记文章 ID 和 URL，启用每 24 小时一次、30 天引用观察窗口的网页复测。可单独修改复测设置。
5. 发布状态来自网站 API；公开页面能否访问、正文匹配、搜索收录和 AI 回答引用分别验证，不由 API 发布状态推断。

正文转换使用 [markdown-it 15.0.2](https://markdown-it.github.io/markdown-it/) 保留段落、换行、标题、嵌套列表、表格、引用、强调、代码块及有效链接。原始 HTML 作为文字转义，不执行脚本或嵌入。HTTPS 图片保留外部地址，仅输出 WordPress 正文过滤规则允许的属性，不自动上传媒体库；非 HTTPS 图片以替代文字显示。相对链接和不支持的协议保留原文。分类/标签、媒体上传和特色图尚未自动同步。

预览不加载外链图片、不允许链接跳转；实际网站主题会影响样式，图片可用性需到目标网站核对。创建时重新校验预览摘要，稿件、事实或解析器版本变化则拒绝旧预览。旧版执行回执继续按其原始 HTML 核对，不重新转换正文。外部网站可能通过插件修改内容；返回内容不一致时会保留回执并要求核对，不覆盖远端改稿。

## 不确定请求与恢复

- 每次创建使用固定请求编号。响应丢失后恢复相同编号，不重复创建文章。
- 取得远端文章 ID 后按 ID 核对；创建响应丢失且没有 ID 时，按提交标识查询远端文章。只接受唯一匹配且标题/正文与快照一致的结果。找不到或匹配多篇时不自动新建。
- 发布响应丢失后先核对已有文章。若已经发布，恢复回执及本地链接登记，不再次发布。
- 远端正文变化显示「待核对」；已登记的文章转回草稿等其他状态时，同步保存当前状态并暂停自动复测。
- HTTP 跳转不携带凭据继续访问；认证、网络或非 JSON 响应会保留失败原因。不得把接口成功配置当作已经发布。
- 备份恢复保留已发生的外部调用回执，停用网站连接并要求重新验证。删除品牌会移除其网站凭据；备份不恢复凭据。

同一工作区的网站写入期间禁止并发编辑，以固定本地提交版本。远端读取与发布是两个 WordPress 请求，不能锁住网站上其他编辑者的同时操作；正式业务上线前仍应核对远端成稿。工作台不自动修改网站已有内容，也不自动删除或撤回文章。

## 容量与验收状态

每工作区保留最多 1000 条网站执行回执，页面显示最近 100 条；单条可导出，完整业务备份包含全部回执。稿件标题最多 300 字，正文最多 100000 字符，排版 HTML 最多 450 KB。发布请求不占用模型调用额度。

19 组原有测试验证了接口合同、加密、权限、品牌隔离、草稿/发布回执、响应丢失、唯一匹配、改稿阻断、并发排他、恢复保护和前端请求编号。新增 13 组排版和预览测试，覆盖提交一致性、旧回执兼容、版本失效、作用域及注入防护。真实客户 WordPress 账号及正式站点首次写入尚未验收；没有已授权站点时不会自动向任意网站发送文章。


## 0.44：媒体库封面

连接验证会分别读取文章编辑、发布与媒体上传权限。上传 PNG/JPEG（最多 8 MiB）时填写标题、普通文字替代说明和可选图注；替代文字中的连续 ASCII 空格会按 WordPress 规则归一化，HTML、编码序列或无效字符在上传前拒绝。成功回执保留图片摘要、尺寸、远端编号、实际 URL 和网站。

创建草稿时可选该网站已核对的封面，并在提交前重新核对远端图片说明；更换网站、远端说明变化或结果未确认时不能继续使用该图片。响应丢失后保留原上传编号，用“核对媒体回执”查找原文件，不自动重复上传。媒体上传不会自动发布文章，也不消耗模型额度。

这些流程已通过受控接口测试；客户自有 WordPress 的真实权限、插件差异和首次上传/发布仍需实际站点验收。正文图片仍按 Markdown 外链处理；本功能为媒体库上传与特色图选择。
