# 今天工作台
Mode: Operate
Build path: code-led

## Direction contract

### World
用户指定光感黑暗高级科技。黑曜石表面、冷白文字、青蓝折射光。参考 Paper Shaders 的光材质与 Motion Primitives 的反馈方式；只参考设计，不引入其源码或依赖。主场景是用户在桌面长期操作业务。

### First viewport
固定侧栏与清晰标题。主区域只给一个与真实状态对应的下一步：继续原任务、确认原稿或选择账号；已有内容时保留写新文章。业务资料、内容确认、发布结果构成三步导航。已创建流程与待核对资料优先，AI 效果简要说明并链接原文；目标、平台与后台设置折叠。

### Signature interaction
鼠标在主行动区域移动时局部折射光响应。光效默认开启，不提供开关按钮。下一步随真实任务、稿件版本及回执改变，不把光效当作采样成功或正在发布的证据。

### System
统一暗色语义 token，适配表单、侧栏、弹窗、待确认和效果页；保留浅色选项。重点按钮冷青，警告/错误仍以文字和独立语义色显示。

### Motion and access
局部 Canvas 光带；单个动画循环、离屏/隐藏页暂停，reduced-motion 静态降级，移动端降低分辨率。Tab 可访问主要操作、三步导航和展开设置，按钮有明确名称；全站无装饰粒子或外部资源加载。

### Truth and tradeoffs
使用本机真实数据，零样本明确显示尚未采样；新增平台探索只读，不触发付费模型。风险为低性能设备动画负担，因此提供系统减少动态效果适配和离屏暂停机制。用户已明确选择精致光感：黑曜石底色、局部光晕、鼠标跟随高光，适合长期办公。
